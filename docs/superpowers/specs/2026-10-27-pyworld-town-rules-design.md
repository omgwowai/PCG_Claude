## 1. 现状：这个场景的城镇规则（2026-10-27 的 W6）

城镇由 W6（`stages/w06_settlements.py` + `world/settle.py` + `world/rules.py`）在一个 Python 节点里生成，原生节点只做
地形写回、建筑形状语法和网格生成。按 City Sample 的"阶段 → 规则表"方式整理如下。

### 1.1 聚落分级（相当于 City Sample 的 district class）

| 规则 | 值 | 位置 |
|---|---|---|
| 类型由地点半径决定 | 半径 ≥ 200 m 镇（Town），≥ 120 m 村（Village），其余小村（Hamlet） | `rules.KIND_RADII` |
| 每类最少建筑数（验收） | 镇 60、村 20、小村 5 | `rules.MIN_BUILDINGS` |
| 处理顺序 | 半径大的先排；所有聚落共用一个"已占用"环索引，互不重叠 | `w06.run` |

### 1.2 地形平台

| 规则 | 值 |
|---|---|
| 平台 | 半径内拟合一个平面，坡度夹到 ≤ 4°（`MaxPlatformSlope`），在路、河走廊上不动（`keep_fn`） |
| 广场 | 镇 / 村中心 18 m 半径垫平，150 cm 地砖 |
| 街道 | 走廊压平（半宽 2 m + 1 m 过渡） |
| 地块 | 每栋建筑的足迹按其平均地面垫平（2 m 平、4 m 过渡），最后再锁一次（+1 m） |
| 路基 | 所有地块之后恢复路走廊（建筑因此离路至少 16 m） |

### 1.3 地标

| 规则 | 值 |
|---|---|
| 教堂 | 镇和村各 1 座，25 × 14 m，High；带 9 × 9 m 钟楼（Tower），放在教堂侧边 |
| 镇公所 | 只有镇，18 × 13 m，High |
| 朝向 | 先占"最宽的方向"（离道路方向最远的方位），面向广场；挡住就在 ±60°、+4 m 内找（`LANDMARK_TRIES`） |

### 1.4 街道（2026-10-27 起是有机生长）

| 规则 | 镇 | 村 | 小村 |
|---|---|---|---|
| 从广场出发的小巷数 | 3 | 2 | 0 |
| 穿镇道路上分出小巷的间距 | 80 m | 110 m | 60 m |
| 街道总长预算 | 1 900 m | 750 m | 200 m |
| 单条最长 | 260 m | 170 m | 90 m |
| 分枝层数 | 2 | 1 | 0 |

每 10 m 一步，航向做带衰减的随机游走（σ 4°、单步 ≤ 8°）；每步 15 % 概率分出支巷（70–110°）；15 m 内碰到别的街 / 路就并上去成 T 字；
边界是一圈噪声（0.72–0.94 倍半径）；碰到河、建筑停。

### 1.5 分区（City Sample：Small / Medium / Large 区；这里是"中心 → 外围"）

| 区 | 到中心的距离 | 用途 |
|---|---|---|
| core 核心 | < 0.35 半径 | 商铺、住宅 |
| residential 住宅 | 0.35–0.75 | 住宅为主 |
| outskirts 外围 | > 0.75 | 农舍（屋后农田）、谷仓、棚屋 |

### 1.6 地块与建筑类型（相当于 lot → building 的规则表）

沿每条街和穿镇道路的两侧，每隔"面宽 + 3–6 m 空隙"放一块；退线：街 2.5 m，路 16 m（走廊外）。类型按区加权抽取、按聚落类型封顶：

| 类型 | 面宽 × 进深 (m) | 高度组 | 权重（核心 / 住宅 / 外围） | 上限（镇 / 村 / 小村） | 其它 |
|---|---|---|---|---|---|
| Shop 商铺 | 8–12 × 9–12 | Mid / High | 3 / 0.5 / – | 24 / 6 / 0 | |
| House 住宅 | 8–11 × 8–11 | Low / Mid | 2 / 5 / 1 | 150 / 50 / 10 | |
| Farmhouse 农舍 | 10–14 × 9–12 | Low | – / – / 3 | 10 / 6 / 3 | 屋后 25–40 × 30–50 m 农田 |
| Barn 谷仓 | 14–18 × 10–14 | Mid | – / – / 1.5 | 6 / 4 / 2 | |
| Shed 棚屋 | 8–9.5 × 8–9.5 | Low | – / 0.3 / 2 | 12 / 6 / 4 | |

### 1.7 建筑本身（这是最弱的一环）

| 规则 | 值 |
|---|---|
| 立面 | **所有建筑共用一个**引擎自带的模板形状语法 `SGD_Bldg_B_Advance_Template`，按 4 个高度组（Low 6 m / Mid 7.5 m / High 10.5 m / Tower 19.5 m）各一个 `Assign_ShapeGrammarDefinition` 节点；墙是彩色条纹的调试网格 |
| 屋顶 | 一个转了 45° 的立方体（上半截当坡屋顶） |
| 塔尖 | 锥体 |
| 地基 | 立方体 |
| 限制 | 足迹任一边 < 约 8 m 整个语法节点失败（`rules.MIN_EDGE`，trap 94） |

### 1.8 街道家具与地表（W8、W9）

街道每 30 m 一盏路灯（左右交替）；广场一圈 6 张长椅；街、广场、农田在 W9 刷成 Dirt。

### 1.9 和 City Sample 对照：缺什么

| City Sample 的建筑系统 | PyWorld 现状 |
|---|---|
| 27 个样式码，每个有 tooltip 元数据（外观 / 类型 / 年代），三个尺寸类各自一份白名单（`BuildingsStyles`） | 没有样式；一种灰盒 |
| BDF：每个样式一条竖向语法（`[LV0][LV1][LV2]*[LV3]`，`*` 重复）、最小墙宽、最小 / 最大楼高、屋顶数据 | 4 个固定高度 |
| 每层一行：层高、三个水平语法 F0 / F1 / F2，按墙长阈值 `FLengths` 选用，`IsTopper` | 无 |
| 模块表：符号、尺寸、网格、可缩放、有窗、有道具、枢轴偏移；外角 `C_E`、角帽 `C_CE` | 无 |
| 高度来自噪声贴图（每类 min..max），HighRise 区 ×1–5 | 按类型随机选组 |
| 立面道具（灯、遮阳篷、招牌、空调）、屋顶装配体 | 无 |
| 材质 / 颜色变化 | 无 |

## 2. 新规则：模块化建筑系统

### 2.1 总体数据流（每栋建筑）

```
地块（类型、区、聚落类型、面宽 / 进深、朝街的一边）
  → 原型 archetype（rules.ARCHETYPES：样式白名单与权重、层数范围、底层用途、道具概率）
  → 样式码 style（bdf.STYLES：竖向语法、各层、最小墙宽、屋顶、调色板、tooltip）       ← City Sample 的 BuildingsStyles + BDF 行
  → 层数（聚落高度噪声场 × 区的范围，面向广场 +1）                                   ← City Sample 的高度噪声贴图
  → 竖向语法展开成层序列（[G][TR][N][U]*[RT] …）
  → 每层每面墙：按墙长选水平语法 F0 / F1 / F2，求解模块序列（重复 *、可缩放模块吸收余量）   ← BDF 的 F0/F1/F2 + FLengths
  → 角：每个顺时针边的起点放外角模块（C_E）；石材家族的角宽逐层不同，用端区 + 填充让窗洞上下对齐
  → 替换规则：正面底层中间开门（门可跨层：石材大门跨基座 + 一层，镇公所 / 教堂大门再跨腰线）；商铺底层每个窗洞加遮阳篷、一块挑出招牌；
    门上一层放阳台；门两侧壁灯；镇公所铭牌
  → 屋顶装配：Roof_Kit_00 的四坡顶（四个斜脊角块 + 长边直段，直段按概率换成老虎窗段），坡度按样式，烟囱
  → 室内遮挡块（窗后是暗色，不透光）、石材勒脚
  → 实例（位置、旋转、缩放、网格、材质覆写 Mat0）→ 原生 Static Mesh Spawner（按属性选网格和材质）
```

每层：层高、模块表（开间、壁柱、角、填充）、三个水平语法 F0 / F1 / F2 + 阈值 `FLengths`（墙短用 F0），`IsTopper`。
例（F02 楼层）：F0 `[S][P,S]*`（全是 400 开间），F1 `[S][P,L]*[P,S]`（两端小、中间 500），F2 `[S][P,L,P,S]*`（大小交替）；阈值 1 200 / 2 000 cm。

### 2.4 水平语法与求解（`pypcg/world/grammar.py`）

语法用 PCG 引擎的写法（`PCGGrammar.h`）：`[A,B]` 模块序列，`*` 重复任意次、`+` 至少一次、`3` 固定次数，`{A:2,B:1}` 按权重随机。
求解 = 给定墙段长度 U，枚举各重复段的次数（两个 `*` 时偏向均分，门居中），让可缩放模块（开间）的统一缩放系数最接近 1、且在
[0.85, 1.2] 内；壁柱、角不缩放。无解时退到 F0，再退到"一整块缩放开间"。每面墙的开间序列在各层共用（窗洞上下对齐）；
正面底层有门 / 商铺时单独求解。

### 2.6 高度规则

每个聚落一张高度噪声场 `h(x, y) = value_noise(x / 70 m, y / 70 m, seed)`（City Sample 用噪声贴图），
`层数 = lo + floor(h × (hi − lo + 1))`，面向广场的建筑 +1（不超过样式上限）。聚落等级定天际线（City Sample 每个区一个高度带）：
村和小村的核心区与住宅区，住宅和商铺的 `lo` / `hi` 各减 1（至少 1 层）；外围的农舍和地标各处一样（`rules.RANK_STOREYS`，
最终评审时看村的截图后加的）。

### 2.7 地块规则的调整

- 空隙按区：核心 0（**联排**：相邻建筑贴在一起，弯街上按 1 m 步长找下一个空位），住宅 2.5–5 m，外围 4–8 m。
- 面宽 / 进深按原型：联排商铺 / 住宅窄而深（5.5–11.5 × 9–13 m）；最小边不再受旧语法的 8 m 限制，改为样式的最小墙宽（F01 / F02 5 m，F00 6.5 m）。
- 镇公所改成长边朝广场（13 × 18 m）。
- 重叠判定改成"内部相交"（贴边不算），汇总里 `overlaps` 仍须为 0。
- 入口台阶（最终评审时加）：楼面只向街道高度靠 60 cm，陡坡上门会高出门前地面。W6 量门前 60 cm 处的高差 `door_rise`，
  高出 > 20 cm 的门前摆石灰石台阶（等分高差、每级 ≤ 25 cm、踏面 32 cm、至多 6 级）。
- 悬空的附属房（最终评审时加）：邻楼的台地切挖会切走屋后附属房脚下的地（实测一栋离地 3.3 m）；楼面比脚下平均地面高
  > 1.5 m 的附属房不放，地块留作院子。

### 2.8 屋顶（`Roof_Kit_00` 四坡顶装配）

屋顶矩形 = 足迹外扩檐口挑出（F02 45、F01 40、F00 20 cm），长边做脊。缩放 s = 进深 / 1 200，四个角块各占 (进深 / 2)²，
长边中间用 300·s 的直段填满（X 再微调），Z 缩放 s·k；k 让坡度从 23° 到约 47°。直段按样式概率换成老虎窗段（k ≤ 1.4 时）。
正方形足迹（钟楼）就是四棱锥。烟囱 0–2 个，砖材质，高出屋脊 0.6–1.2 m。

### 2.9 颜色（调色板）

为每个用到的套件材质生成带色调的子材质（`MS_DefaultMaterial` 的 `Albedo Tint`），放在 `/Game/PyPCG/World/Town/`：
抹灰 5 色（奶油、赭、玫瑰、灰绿、灰蓝）、砖 3 色、石 3 色、屋顶 4 色（深板岩、蓝板岩、陶土、褐）。相邻建筑不取同色。
`pyworld_town_materials.py` 生成；纯 Python 侧只拼路径。

### 2.10 图（W6）

- Python 节点新增输出 `Modules`（每个模块一个点：变换、`Mesh`、`Mat0`）→ 原生 `PCGStaticMeshSpawnerSettings`（按属性选网格，
  `bUseAttributeMaterialOverrides`，`MaterialOverrideAttributes = [Mat0]`）。
- 删掉 4 个 `Assign_ShapeGrammarDefinition` 节点和 `Footprints*` 输出；`Parts`（街面、广场地砖）不变；地基立方体换成勒脚模块。
- `Buildings` 表的 `Group` 换成 `Style`，`Height` 换成实测的墙顶 + 屋脊高度，再加 `Floors`、`Tint`、`Roof`、`Shop`。

### 2.11 验收（`checks.accept(6)` 与测试）

- 原有：每类最少建筑数、每个镇 / 村一座教堂、`overlaps == 0`、`on_road == 0`、有实例。
- 新增：用到的样式码 ≥ 5；每栋建筑都有门且门在朝街的一面；每面墙的模块宽度之和 = 墙长（误差 < 1 cm）；开间缩放都在 [0.85, 1.2]；
  每层角模块数 = 4；层数分布：核心平均层数 > 外围；镇里至少 20 % 的建筑是联排（贴着邻居）。

## 3. 实现与验收

1. 纯 Python（先写测试）：`grammar.py`（解析、求解）、`kit.py`（模块表、尺寸自洽）、`bdf.py`（样式表、每个样式在最小墙宽上可解）、
   `building.py`（装配：墙段闭合、角、门、对齐、屋顶覆盖足迹、实例数）、`rules.py` / `settle.py`（原型、样式、层数、联排、门向）、
   `w06`（`Modules` 输出、汇总）、`graphs.build_w06`（原生生成器 + 材质覆写）、`checks.accept(6)`。
2. 材质：`pyworld_town_materials.py` 生成调色板子材质。
3. 编辑器预览：`pyworld_town_preview.py` 在海面测试区摆几栋样例楼，截图核对枢轴、角、门、屋顶、颜色。
4. `pyworld.py build {"stages": [6]}`（0 diff）→ `assign` → `reset {"from": 6}` → W6–W9 `gen` / `read` → `check` → 截图 → `save`。
5. 文档：`docs/pyworld-guide.md` 新增 §8（城镇规则：现状总结 + 新规则 + 结果），traps，CLAUDE.md，memory。

风险：Nanite 模块的实例数（估计 2–4 万）；F00 角宽逐层不同（端区填充）；遮阳篷 / 招牌是 City Sample 的美式图案；
`Albedo Tint` 对整张图集着色（百叶窗也会被染色）。
