# City Sample 体积云：时间演变与预设间平滑过渡 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The ten art-directed volumetric clouds of the City Sample demo level change shape over time, and the current
cloud blends smoothly into a target preset's cloud. Deliverables: the system, 10 motion clips, 5 transition clips and an
HTML page.

**Architecture:**
- The cloud material `M_CS_CumulusCloud` becomes v2. One density body is expanded into slot A (today's parameter names)
  and slot B (`B_` names). Each slot has its own absolute-altitude layer and its own time inputs, and the two are summed
  into one extinction. The HLSL is generated by the pure module `cs_cloud_code.py`.
- A pure, deterministic motion model, `cs_cloud_motion.py`, turns (simulated time, two slots, transition) into every
  value of one frame.
- An editor-side director (`cs_cloud_rt.py`, bridge entry `cs_cloud_director.py`) runs a Slate tick. The tick writes
  those values into one MaterialInstanceDynamic and a few component properties, and records frame-stepped clips.
- Static presets still go through `cs_weather.py apply`. Apply now resolves presets through the pure `cs_wx_resolve.py`,
  which the director shares.

**Tech Stack:** UE 5.8 editor Python over the MCP bridge (`run_unreal_script`), a Custom-HLSL volumetric cloud material,
pytest + numpy + Pillow on system Python 3.14, ffmpeg 8.1.1.

**Spec:** `docs/superpowers/specs/2026-11-12-cs-cloud-motion-design.md`. It is uncommitted, like the rest of the City
Sample weather work.

**Rulings (planner = executor):**
- **R1: how much code the plan contains.** Every pure module, every test and every engine-API script is given in full.
  The HLSL body is given in full too, because a slip there silently changes 22 approved looks.
- **R2: no commit steps.** The user's standing rule is "commit only when asked", and the City Sample weather work is
  uncommitted. Each task ends with a checkpoint instead: the suite is green and the notes are written.
- **R3: spec refinements made on 2026-11-12, before this plan.** All three keep the spec's claim "a transition ends on
  the designed frame" true:
  - the evolution term is the difference of two noise slices;
  - the oscillators are offset so they are neutral at age 0;
  - the front's approach extrapolates linearly for negative ages.
- **R4: no new textures.** The evolution, boil and phase inputs all read the 128³ shape volume or the 64³ detail volume
  that already exist.
- **R5: per-frame component writes.** The director uses a component's Blueprint setter when the setter exists and the
  component is not Static, and verifies the write by reading the value back; otherwise it uses `set_editor_property`.
  Reason: setters do nothing on Static components (spec §0.4).
- **R6: one extra check beyond spec §8: "stills" through the director's MID path,** taken at age 0 and at age 1200 s.
  - Age 0 must match the finals within the noise floor. This shows the MID path reproduces the static look.
  - Age 1200 s must differ from the finals by more than that. This shows the clouds really move.
- **R7: task order.**
  - The resolver (Task 2) comes before the spike (Task 3), because the spike script reads the managed property list
    from it.
  - The spike's noise-floor renders therefore go through the refactored `apply`. That doubles as a check of the
    refactor.

## Global Constraints

- **Level and saving:**
  - The demo level `/CitySamplePCG/Levels/L_CitySamplePCG_Demo` is never saved.
  - Editor autosave stays off while anything here runs.
  - Every editor session ends with `cs_weather.py {"phase": "restore", "to": "original"}` (CLAUDE.md, trap 78).
- **Material rebuilds** (trap 136):
  - Build only with the startup map `/Game/ThirdPerson/Lvl_ThirdPerson` open, and always deferred.
  - Poll `Saved/Reports/cs_weather/assets_result.json` for the result. Never answer a "connection closed" reply with a
    rerun.
  - Switching away from the demo level can crash the editor (traps 79/83): restart the editor instead (runbook R4).
- **Ticks:** no asset save inside a Slate tick callback (trap 132). Every tick is wrapped in `cs_wx_lib.guarded`. No
  transaction or `modify()` per frame.
- **Static looks:** with the director off, the 22 static looks stay within 1.5 × the noise floor of `diff_shots.py`'s
  metric (spec §2.6). The looks are the base, 11 photo weathers and 10 art weathers, with 2 finals each.
- **Budgets** (spec §8):
  - Director CPU per frame: mean ≤ 2 ms.
  - Cloud GPU while playing without a transition: within 10 % of the same preset shown static.
- **Defaults:**
  - Speed 30 simulated seconds per wall second.
  - Transitions: 30 simulated minutes, `light: "full"`.
  - Windows: fade [0, 0.7], form [0.3, 1], light [0.1, 0.9].
  - The star dome exists below 10 lux.
  - The view sample count scale is capped at 1024 / 96.
- **Units:** wind in m/s with the compass heading the air moves toward (north = +X, east = +Y). Distances in km. Times in
  simulated seconds; lifetimes and periods in simulated minutes.
- **Data edits** (trap 135): `cs_weather_art.py`, `cs_weather_presets.py`, `cs_weather.py` and `cs_sky_assets.py` are
  untracked. Before editing one, copy it to `Saved/Reports/cs_weather2/backup/<name>.2026-11-12`.
- **Other sessions:**
  - Editors of PCG_Codex or WeatherSystem may share the engine and the GPU (memory two-editors-running). Never kill an
    editor that is not this project's.
  - A GPU timing only counts against another one taken in the same session and conditions.
  - Never touch files other sessions left uncommitted: `docs/pyworld-guide.md`, `Content/Python/pyworld_*`,

## Review Focus

1. **A `to` the director cannot honour** must be refused with a reason, and nothing changes. The cases: an unknown
   preset, the current cloud again, under 10 simulated seconds, a bad `light`, or a second `to` mid-transition.
   → `test_refusals` in Task 7; the editor phase returns `{"refused": ...}` (Task 9, step 5).
2. **Leaving a night preset** (moonlit → day): the stars fade and the dome disappears once the light passes 10 lux. No
   dome is left behind. → `test_dome_enters_and_leaves` in Task 7.
3. **Hours of play:** offsets stay wrapped in [0, 1), and the remaining advection budget is reported.
   → `test_wrapped_values_stay_in_unit_interval_for_long_runs` and `test_adv_budget_long_run` in Task 5; `state` shows
   `adv_budget_km` (Task 8).
4. **A moving camera between cameras that differ** (in aspect ratio, or `target` instead of a rotation), e.g.
   Towers 1.6 → Storm 2.0, or Wide → Sea: there is one output size per clip, and the target camera's heading is reached.
   → `test_camera_at_endpoints_and_target_cameras` in Task 10.
5. **`cs_weather.py restore` while the director runs:** the director stops first, the cloud gets its original material
   back, and the level packages end clean. → editor check in Task 9, step 6.

## Editor runbook

Bridge calls are written `MCP run_unreal_script("<script>.py", {args})`. A reply of
`Unreal editor not connected on 127.0.0.1:8777` means the editor is not up: start it (R4, step 3) or ask the user.

**R1: find the editor and its level.**
1. `netstat -ano | grep "127.0.0.1:8777.*LISTENING"`: the last column is the PID of this project's editor.
2. `MCP run_unreal_script("cs_wx_status.py")` returns `world`, `mem`, `batch` and `shots`. Note the world path.

**R2: open the demo and apply the base look.** Only from the startup map (`world` starts with
`/Game/ThirdPerson/Lvl_ThirdPerson`) or with the demo already open. From any other level, use R4.
1. `MCP run_unreal_script("cs_open_demo.py")` returns `{"loaded": true, "level": "/CitySamplePCG/Levels/L_CitySamplePCG_Demo..."}`,
   or `{"already": ...}` when the demo is open. In both cases continue.
2. `MCP run_unreal_script("cs_clear_sky.py", {"phase": "apply"})` → no `abort`.
3. `MCP run_unreal_script("cs_weather.py", {"phase": "cams"})` → every camera of `CAMERAS` listed.
4. `MCP run_unreal_script("cs_weather.py", {"phase": "apply", "preset": "base"})` → `cloud_mi.asset` ends with
   `MI_CS_CumulusCloud_Clear`.

**R3: end a session.**
1. `MCP run_unreal_script("cs_cloud_director.py", {"phase": "stop"})`. Skip this until Task 8 exists.
2. `MCP run_unreal_script("cs_weather.py", {"phase": "restore", "to": "original"})` → `clean.refused` null,

**R4: restart the editor onto the startup map.**
1. If the demo is open, do R3 first.
2. `MCP run_unreal_script("_quit_editor.py")`, then wait in the background:

```python
    lines += ["Cons = consM;", "AO = sig > 0.0 ? aoS / sig : 1.0;", "Alb = sig > 0.0 ? albS / sig : 1.0;", "return sig;"]
    return "\n".join(lines)
```

```python
# cs_wx_resolve.py -- what a City Sample weather preset sets, as plain values (pure Python, no unreal import).
# cs_weather.py apply writes the result into the level, the cloud director (cs_cloud_rt.py, cs_cloud_motion.py) blends
# two results, the offline tests check it. The rule is the one cs_weather.py has used since 2026-11-11: a managed property
# takes the call's override, else the preset's value, else the 10:00 base value, else the level's original value from the
# snapshot (Saved/Reports/cs_weather2/original_extra.json), else it is left alone.
import cs_weather_presets as P

SECTIONS = ["DirectionalLightComponent", "SkyAtmosphereComponent", "SkyLightComponent", "VolumetricCloudComponent",
            "ExponentialHeightFogComponent"]
BASE_PRESET = {"title": "上午 10:00 晴天积云（基线）", "sun": P.BASE_SUN + [""], "set": {},
               "cloud": {"mi": "MI_CS_CumulusCloud_Clear", "params": {}}, "ppv": {}, "shots": []}


def preset(name):
    return BASE_PRESET if name == "base" else P.PRESETS[name]


def names():
    """Every preset the driver knows: the 10:00 base, the photo weathers, the art weathers."""
    return ["base"] + list(P.ORDER) + list(P.ART_ORDER)


def managed(extra_keys=()):
    """{section: properties}: the 10:00 base properties, every property any preset sets, and extra_keys."""
    out = {s: set(P.BASE.get(s, {})) for s in SECTIONS}
    keys = [k for p in P.PRESETS.values() for k in p.get("set", {})] + list(extra_keys)
    for key in keys:
        section, prop = key.split(".", 1)
        out.setdefault(section, set()).add(prop)
    return out


def managed_ppv():
    keys = set(P.BASE["PPV"]) | set(P.CAMERA_LOOK)
    for p in P.PRESETS.values():
        keys |= set(p.get("ppv", {}))
    return keys


def resolve(name, snapshot, overrides=None):
    """Everything preset `name` sets. overrides = an apply call's {"set", "cloud", "ppv", "sun"}."""
    o = overrides or {}
    p = preset(name)
    over_set = o.get("set") or {}
    comps = {}
    for section, props in managed(over_set.keys()).items():
        vals = {}
        for prop in sorted(props):
            key = section + "." + prop
            if key in over_set:
                vals[prop] = over_set[key]
            elif key in p.get("set", {}):
                vals[prop] = p["set"][key][0]
            elif prop in P.BASE.get(section, {}):
                vals[prop] = P.BASE[section][prop]
            else:
                v = (snapshot or {}).get("components", {}).get(section, {}).get(prop)
                if v is not None:
                    vals[prop] = v
        comps[section] = vals
    sun = o.get("sun") or p["sun"][:2]
    params = p["cloud"].get("params", {})
    cloud = dict(P.BASE_CLOUD)
    cloud.update(P.CLOUD_NEUTRAL)
    cloud.update({k: v[0] for k, v in params.items()})
    over_cloud = dict(o.get("cloud") or {})
    layer = comps.get("VolumetricCloudComponent", {})
    if "LayerKm" not in over_cloud and "LayerKm" not in params:
        cloud["LayerKm"] = layer["layer_height"]
    if "BottomKm" not in over_cloud and "BottomKm" not in params:
        cloud["BottomKm"] = layer["layer_bottom_altitude"]
    cloud.update(over_cloud)
    ppv = dict(P.BASE["PPV"])
    if name != "base":
        ppv.update({k: v[0] for k, v in P.CAMERA_LOOK.items()})
    ppv.update({k: v[0] for k, v in p.get("ppv", {}).items()})
    ppv.update(o.get("ppv") or {})
    night = {k: v[0] for k, v in p["night_sky"].items()} if p.get("night_sky") else None
    cvars = dict(P.BASE_CVARS)
    cvars.update(p.get("cvars", {}))
    return {"name": name, "sun": [float(sun[0]), float(sun[1])], "components": comps,
            "cloud": {k: float(v) for k, v in cloud.items()}, "mi": p["cloud"]["mi"], "ppv": ppv,
            "night_sky": night, "cvars": cvars, "motion": p.get("motion")}
```

```python
# with their finals (wx_<preset>_<cam>_final.png) using diff_shots.py's metric: the largest channel mean of the absolute

sys.path.insert(0, os.path.dirname(__file__))

W = np.array([0.2126, 0.7152, 0.0722], dtype=np.float32)


def short(label):
    return "hero" if label == "CS_SkyCam" else label.replace("CS_WX_", "").replace("CS_ART_", "").lower()


def cams(name, first_only):
    labels = BASE_CAMS if name == "base" else [s[0] for s in P.PRESETS[name]["shots"]]
    return labels[:1] if first_only else labels


def metric(a_path, b_path):
    a, b = D.load(a_path), D.load(b_path)
    if a.shape != b.shape:
        return None
    d = np.abs(a - b)
    dl = np.abs(D.box(a, 8) @ W - D.box(b, 8) @ W)
    return {"mean": round(float(d.reshape(-1, 3).mean(axis=0).max()), 3),
            "p999": round(float(np.percentile(dl, 99.9)), 3)}


def compare(presets, tag, first_only):
    rows = []
    for name in presets:
        for label in cams(name, first_only):
            fin = os.path.join(SHOTS, "wx_%s_%s_final.png" % (name, short(label)))
            new = os.path.join(SHOTS, "wx_%s_%s_%s.png" % (name, short(label), tag))
            row = {"shot": os.path.basename(new)}
            if not (os.path.exists(fin) and os.path.exists(new)):
                row["missing"] = True
            else:
                m = metric(fin, new)
                row.update(m if m else {"size_differs": True})
            rows.append(row)
    return rows

    sys.stdout.reconfigure(encoding="utf-8")
    ap = argparse.ArgumentParser()
    ap.add_argument("--tag", required=True)
    ap.add_argument("--presets", nargs="*")
    ap.add_argument("--make-floor", action="store_true")
    ap.add_argument("--expect-change", action="store_true")
    ap.add_argument("--first-cam", action="store_true")
    ap.add_argument("--factor", type=float, default=1.5)
    ap.add_argument("--floor", default=os.path.join(OUT, "noise_floor.json"))
    a = ap.parse_args()
    presets = a.presets or ["base"] + list(P.ORDER) + list(P.ART_ORDER)
    rows = compare(presets, a.tag, a.first_cam)
    os.makedirs(OUT, exist_ok=True)
    if a.make_floor:
        good = [r for r in rows if "mean" in r]
        if len(good) != len(rows):
            print("missing shots:", [r["shot"] for r in rows if "mean" not in r])
            return 1
        floor = {"mean": max(r["mean"] for r in good), "p999": max(r["p999"] for r in good), "from": a.tag,
                 "shots": rows}
        json.dump(floor, open(a.floor, "w", encoding="utf-8"), indent=1)
        print("floor", {k: floor[k] for k in ("mean", "p999")})
        return 0
    floor = json.load(open(a.floor, encoding="utf-8"))
    lim_m, lim_p = a.factor * floor["mean"], a.factor * floor["p999"]
    bad = []
    for r in rows:
        if "mean" not in r:
            bad.append(r)
        elif a.expect_change and not (r["mean"] > lim_m or r["p999"] > lim_p):
            bad.append(r)
        elif not a.expect_change and (r["mean"] > lim_m or r["p999"] > lim_p):
            bad.append(r)
    res = {"tag": a.tag, "floor": {"mean": floor["mean"], "p999": floor["p999"]}, "factor": a.factor,
           "expect_change": a.expect_change, "rows": rows, "bad": bad}
    json.dump(res, open(os.path.join(OUT, "regress_%s.json" % a.tag), "w", encoding="utf-8"), indent=1)
    for r in rows:
        print(r)
    print("%d shots, %d outside the limits (mean %.2f, p999 %.2f)" % (len(rows), len(bad), lim_m, lim_p))
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
# cs_cloud_motion.py -- the motion model of the City Sample cloud director (docs/superpowers/specs/2026-11-12-cs-cloud-
# motion-design.md §3-4): from the simulated time, the two cloud slots and the transition, every value one frame writes.
# Pure Python (no unreal import) and deterministic: the director (cs_cloud_rt.py) calls it every editor tick and for
# every recorded frame; the offline tests (Tools/cs_weather/tests) call it directly.
#
# Units: simulated seconds; wind m/s; distances km; compass headings in degrees, north = +X, east = +Y (a camera's UE
# yaw is its compass heading). A resolved preset is a cs_wx_resolve.resolve() result. A slot is
#   {"preset": name, "base": resolved cloud params, "motion": motion_for(...), "tau0": simulated time at age 0,
#    "vc": its VolumetricCloudComponent values, "clouds_light": its DirectionalLight cast_shadows_on_clouds}
# and a state is {"slots": {"A": slot, "B": slot or None}, "look": the resolved preset whose light / look is on screen,
#                 "trans": None or the running transition}.
import math

import cs_cloud_code as CC

SPEED = 30.0                  # default simulated seconds per wall second
EVO_LOOP = 8.0                # lifetimes per z period of the evolution / phase noises (8 Worley cells per period)
FORM_WINDOW = [0.3, 1.0]      # default share of a transition in which the incoming slot forms
FADE_WINDOW = [0.0, 0.7]      # ... and the outgoing slot dissipates
ADV_BUDGET_KM = 13000.0       # |Adv| below which the shape noise keeps < 1/4 texel of float32 quantization (spec §3.6)
LIGHT = "DirectionalLightComponent"
CLOUD = "VolumetricCloudComponent"
WRAPPED = {"DetailOffU", "DetailOffV", "DetailOffW", "Detail2OffU", "Detail2OffV", "Detail2OffW", "EvoPhase",
           "BoilShape", "BoilBillow", "BoilTurret", "MammaPhase", "MackerelPhase", "LumpPhase", "RainFall"}
GLOBAL_PARAMS = ["PixelAngle"] + [n for n, _d, _g in CC.EXTRA_SCALARS]
# motion keys and defaults (None = derived from the preset by motion_for); a preset's "motion" data overrides any of them
MOTION_KEYS = {
    "wind_ms": None, "wind_deg": 250.0, "detail_speed": 1.0, "boil_detail_ms": 0.0, "boil_shape_ms": 0.0,
    "boil_billow_ms": None, "boil_turret_ms": None, "evo_amt": 0.4, "evo_life_min": 20.0, "evo_scale_km": None,
    "mamma_life_min": 10.0, "mackerel_life_min": 15.0, "lump_life_min": 15.0, "rain_fall_ms": 8.0, "clip_speed": 60.0,
    "mods": None, "form_window": None, "fade_window": None,
}


def frac(x):
    return x - math.floor(x)


def heading(deg):
    """Unit vector (x = north, y = east) of a compass heading."""
    a = math.radians(deg)
    return math.cos(a), math.sin(a)


def ease(x):
    x = min(max(x, 0.0), 1.0)
    return x * x * (3.0 - 2.0 * x)


def sub(x, a, b):
    """Eased position of x inside [a, b]: 0 before a, 1 after b."""
    if b <= a:
        return 1.0 if x >= b else 0.0
    return ease((x - a) / (b - a))


def _val(e):
    """A data entry is [value, why]; a plain value passes through."""
    if isinstance(e, list) and len(e) == 2 and isinstance(e[1], str):
        return e[0]
    return e


def _storm(base):
    return base.get("CellStrength", 0.0) > 0.0 and base.get("LensAmt", 0.0) <= 0.0


def motion_for(raw, base):
    """The motion of a slot: MOTION_KEYS, the defaults of spec §3.5 derived from its resolved cloud params `base`, then
    the preset's own "motion" data `raw` ({key: [value, why]}, "mods": [[modulator, why], ...]) on top."""
    m = dict(MOTION_KEYS)
    bottom = base["BottomKm"]
    m["wind_ms"] = 6.0 if bottom < 2.0 else (12.0 if bottom < 6.0 else 30.0)
    m["boil_billow_ms"] = 1.0 if base.get("BillowAmt", 0.0) > 0.0 else 0.0
    m["boil_turret_ms"] = 5.0 if _storm(base) and base.get("TurretAmt", 0.0) > 0.0 else 0.0
    m["evo_scale_km"] = base["WeatherScaleKm"] / 4.0
    m["mods"] = []
    if _storm(base) and base.get("OvershootKm", 0.0) > 0.0:
        m["mods"].append({"param": "OvershootKm", "osc": [0.3 * base["OvershootKm"], 8.0, 0.0]})
    m["form_window"] = [0.0, 1.0] if _storm(base) else list(FORM_WINDOW)
    m["fade_window"] = list(FADE_WINDOW)
    for key, e in (raw or {}).items():
        if key not in MOTION_KEYS:
            raise KeyError("unknown motion key %s" % key)
        if key == "mods":
            m[key] = [_val(item) for item in e]
        else:
            v = _val(e)
            m[key] = list(v) if isinstance(v, list) else v
    return m


def time_params(base, m, tau):
    """The time inputs of one slot at age tau (spec §2.3, §3.2). Wrapped values are computed in double precision."""
    v = m["wind_ms"] * 1.0e-3
    hx, hy = heading(m["wind_deg"])
    ax, ay = v * tau * hx, v * tau * hy
    out = {"AdvX": ax, "AdvY": ay}
    sa = math.radians(base["StretchAngle"])
    sdx, sdy = math.cos(sa), math.sin(sa)
    kd = m["detail_speed"]
    qx = (ax * sdx + ay * sdy) * kd / max(base["StretchX"], 0.001)
    qy = (-ax * sdy + ay * sdx) * kd
    s = base["DetailScaleKm"]
    rise = m["boil_detail_ms"] * 1.0e-3 * tau
    d = (-qx / s, -qy / s, -rise / s)            # the detail lookup samples at x - (air displacement)
    for i, c in enumerate("UVW"):
        out["DetailOff" + c] = frac(d[i])
        out["Detail2Off" + c] = frac(2.71 * d[i])
    out["EvoAmt"] = m["evo_amt"]
    out["EvoScaleKm"] = m["evo_scale_km"]
    out["EvoPhase"] = frac(tau / (EVO_LOOP * m["evo_life_min"] * 60.0))
    out["BoilShape"] = frac(-m["boil_shape_ms"] * 1.0e-3 * tau / base["ShapeScaleKm"])
    out["BoilBillow"] = frac(-m["boil_billow_ms"] * 1.0e-3 * tau / (base["BillowScaleKm"] * 8.0))
    out["BoilTurret"] = frac(-m["boil_turret_ms"] * 1.0e-3 * tau / (base["TurretScaleKm"] * 8.0))
    out["MammaPhase"] = frac(tau / (EVO_LOOP * m["mamma_life_min"] * 60.0))
    out["MackerelPhase"] = frac(tau / (EVO_LOOP * m["mackerel_life_min"] * 60.0))
    out["LumpPhase"] = frac(tau / (EVO_LOOP * m["lump_life_min"] * 60.0))
    out["RainFall"] = frac(0.08 * m["rain_fall_ms"] * 1.0e-3 * tau)
    return out


def apply_mods(params, m, tau):
    """The preset's modulators (spec §3.3); every one leaves params unchanged at tau = 0."""
    for mod in m["mods"]:
        if "osc" in mod:
            amp, period_min, ph = mod["osc"]
            w = 2.0 * math.pi * tau / (period_min * 60.0)
            params[mod["param"]] += amp * (math.sin(w + ph) - math.sin(ph))
        elif "approach" in mod:
            dist, speed, deg = mod["approach"]
            v = speed * 1.0e-3
            d = v * tau if tau < 0.0 else dist * (1.0 - math.exp(-v * tau / max(dist, 1.0e-6)))
            hx, hy = heading(deg)
            ps = mod["params"]
            for i in range(0, len(ps), 2):
                params[ps[i]] += d * hx
                params[ps[i + 1]] += d * hy
        else:
            raise KeyError("unknown modulator %s" % sorted(mod))
    return params


def new_slot(resolved, t, age=0.0):
    """A slot holding the resolved preset at simulated time t, aged `age` at t. The incoming slot of a transition starts
    at minus the transition's length, so it reaches age 0 -- the designed look -- when the transition ends."""
    base = dict(resolved["cloud"])
    light = resolved["components"].get(LIGHT, {})
    return {"preset": resolved["name"], "base": base, "motion": motion_for(resolved.get("motion"), base),
            "tau0": float(t) - float(age), "vc": dict(resolved["components"].get(CLOUD, {})),
            "clouds_light": bool(light.get("cast_shadows_on_clouds", False))}


def slot_params(slot, t):
    """Every material parameter of a slot at simulated time t (no transition tracks)."""
    tau = t - slot["tau0"]
    p = dict(slot["base"])
    p.update(time_params(slot["base"], slot["motion"], tau))
    apply_mods(p, slot["motion"], tau)
    p["SlotOn"] = 1.0
    return p


def adv_km(slot, t):
    """How far the slot's air has moved (km): the float32 precision budget of spec §3.6."""
    return abs(slot["motion"]["wind_ms"] * 1.0e-3 * (t - slot["tau0"]))


def mid_params(pa, pb, glob_a, glob_b, w):
    """The MID's values: slot A under the plain names, slot B under "B_" names (only B_SlotOn = 0 when pb is None), the
    shared parameters (GLOBAL_PARAMS) blended from glob_a to glob_b by w."""
    mid = {n: float(pa[n]) for n in CC.SLOT_NAMES}
    if pb is None:
        mid[CC.slot_name("SlotOn", "B")] = 0.0
    else:
        mid.update({CC.slot_name(n, "B"): float(pb[n]) for n in CC.SLOT_NAMES})
    for n in GLOBAL_PARAMS:
        a = glob_a[n]
        b = glob_b[n] if glob_b is not None else a
        mid[n] = float(a + (b - a) * w)
    return mid


def look_static(r, clouds_light=None):
    """The look of one resolved preset: its component values except the cloud component's, the sun, the post-process
    values and the star dome. clouds_light (the cloud slot's cast_shadows_on_clouds) overrides the light's flag."""
    comps = {s: dict(v) for s, v in r["components"].items() if s != CLOUD}
    if clouds_light is not None and LIGHT in comps:
        comps[LIGHT]["cast_shadows_on_clouds"] = bool(clouds_light)
    night = r.get("night_sky")
    return {"components": comps, "sun": [float(r["sun"][0]), float(r["sun"][1])], "ppv": dict(r["ppv"]),
            "dome": bool(night), "stars": dict(night) if night else None}


def new_state(resolved, t):
    return {"slots": {"A": new_slot(resolved, t), "B": None}, "look": resolved, "trans": None}


def frame(state, t, ppv_defaults):
    """Every value of one frame at simulated time t: {"t", "p", "mid", "vc", "look"} (plain play)."""
    if state["trans"] is not None:
        raise ValueError("frame(): this version has no transitions")
    a = state["slots"]["A"]
    return {"t": t, "p": None, "mid": mid_params(slot_params(a, t), None, a["base"], None, 0.0), "vc": dict(a["vc"]),
            "look": look_static(state["look"], a["clouds_light"])}
```

```python
def frame(state, t, ppv_defaults):
    """Every value of one frame at simulated time t: {"t", "p", "f", "g", "mid", "vc", "look"}. During a transition the
    outgoing slot follows its fade tracks, the incoming one its form tracks, and the look moves in the light window."""
    a = state["slots"]["A"]
    pa = slot_params(a, t)
    tr = state["trans"]
    if tr is None:
        return {"t": t, "p": None, "f": None, "g": None, "mid": mid_params(pa, None, a["base"], None, 0.0),
                "vc": dict(a["vc"]), "look": look_static(state["look"], a["clouds_light"])}
    b = state["slots"]["B"]
    raw = progress(state, t)
    p = ease(raw)
    f = _window(p, a["motion"]["fade_window"])
    g = _window(p, b["motion"]["form_window"])
    apply_tracks(pa, fade_tracks(a["base"]), f, forming=False)
    apply_push(pa, fade_push(a["base"]), f)
    pa["SlotOn"] = 0.0 if f >= 1.0 else 1.0
    pb = slot_params(b, t)
    apply_tracks(pb, form_tracks(b["base"]), g, forming=True)
    pb["SlotOn"] = 1.0 if g > 0.0 else 0.0
    clouds_light = (a["clouds_light"] and f <= 0.9) or (b["clouds_light"] and g >= 0.1)
    return {"t": t, "p": raw, "f": f, "g": g, "mid": mid_params(pa, pb, a["base"], b["base"], p),
            "vc": union_vc(a["vc"], b["vc"]), "look": look_trans(state, p, ppv_defaults, clouds_light)}


def _window(p, w):
    return min(max((p - w[0]) / (w[1] - w[0]), 0.0), 1.0)


def _arc(a, b):
    """Signed shortest turn from heading a to heading b (degrees)."""
    return (b - a + 180.0) % 360.0 - 180.0


def _zero_cov(base):
    """A CoverageBias at which the slot's coverage is 0 everywhere (its maximum is CoverageScale + CoverageBias)."""
    return min(base["CoverageBias"] - 1.0, -base["CoverageScale"] - 0.05)


def form_tracks(base):
    """[(param, g0, g1, start)]: while the slot forms (g from 0 to 1) the param goes from start to its value, eased over
    [g0, g1] (spec §4.3). At g = 0 the slot is empty, so switching it on shows nothing."""
    t = [("CoverageBias", 0.0, 0.8, _zero_cov(base)), ("DensityScale", 0.0, 0.6, 0.4 * base["DensityScale"]),
         ("BillowAmt", 0.4, 1.0, 0.0)]
    if base["TypeMax"] > base["TypeMin"]:
        t.append(("TypeMax", 0.2, 1.0, base["TypeMin"]))
    if base.get("MackerelAmt", 0.0) > 0.0:
        t.append(("MackerelGap", 0.0, 0.8, 1.0))
    if _storm(base):
        t += [("CellStrength", 0.0, 0.15, 0.0), ("CellRadiusKm", 0.0, 0.5, 0.35 * base["CellRadiusKm"]),
              ("CellTopH", 0.05, 0.6, 0.05), ("CellSolid", 0.3, 0.7, 0.0),
              ("AnvilRadiusKm", 0.55, 0.9, base["CellRadiusKm"]), ("AnvilShiftKm", 0.6, 1.0, 0.0),
              ("OvershootKm", 0.75, 0.95, 0.0), ("TurretAmt", 0.4, 1.0, 0.0), ("MammaAmt", 0.85, 1.0, 0.0)]
    if base.get("RainDensity", 0.0) > 0.0:
        t.append(("RainDensity", 0.6, 0.9, 0.0))
    if base.get("FrontAmt", 0.0) > 0.0:
        t.append(("FrontAmt", 0.0, 0.4, 0.0))
    if base.get("LensAmt", 0.0) > 0.0:
        t += [("LensCut", 0.0, 0.7, 1.0), ("LensPlates", 0.4, 1.0, 1.0)]
    return t


def fade_tracks(base):
    """[(param, f0, f1, end)]: while the slot dissipates (f from 0 to 1) the param goes from its value to end, eased over
    [f0, f1]. Not the reverse of forming: a storm loses its updraft first, its column collapses, its anvil goes last.
    At f = 1 the slot is empty, so switching it off shows nothing."""
    t = [("CoverageBias", 0.2, 1.0, _zero_cov(base)), ("DensityScale", 0.0, 0.8, 0.3 * base["DensityScale"]),
         ("BillowAmt", 0.0, 0.5, 0.0)]
    if base["TypeMax"] > base["TypeMin"]:
        t.append(("TypeMax", 0.0, 0.6, base["TypeMin"]))
    if base.get("MackerelAmt", 0.0) > 0.0:
        t.append(("MackerelGap", 0.2, 1.0, 1.0))
    if _storm(base):
        t += [("OvershootKm", 0.0, 0.3, 0.0), ("TurretAmt", 0.0, 0.4, 0.0), ("CellSolid", 0.0, 0.5, 0.0),

    if base.get("RainDensity", 0.0) > 0.0:

    if base.get("FrontAmt", 0.0) > 0.0:

    if base.get("LensAmt", 0.0) > 0.0:
        t += [("LensCut", 0.0, 0.8, 1.0), ("LensPlates", 0.0, 0.5, 1.0)]
    return t


def fade_push(base):
    """[(params as x, y pairs, km, heading)]: a dissipating gust front (and its rain) keeps moving forward."""
    if base.get("FrontAmt", 0.0) > 0.0:
        return [(["FrontX", "FrontY", "RainX", "RainY"], FRONT_PUSH_KM, base["FrontAngle"])]

def apply_tracks(params, tracks, x, forming):
    for name, a, b, other in tracks:
        k = sub(x, a, b)
        target = params[name]
        params[name] = other + (target - other) * k if forming else target + (other - target) * k
    return params


def apply_push(params, pushes, f):
    for names, dist, deg in pushes:
        hx, hy = heading(deg)
        d = dist * ease(f)
        for i in range(0, len(names), 2):
            params[names[i]] += d * hx
            params[names[i + 1]] += d * hy
    return params


def union_vc(va, vb):
    """The cloud component during a transition (spec §4.4): the layer covers both slots, the view sample count grows with
    it (capped), tracing distances take the larger, flags are on if either is on; the rest stays the outgoing one."""
    out = dict(va)
    for k, v in vb.items():
        if isinstance(v, bool):
            out[k] = bool(out.get(k, False)) or v
        elif k in ("tracing_max_distance", "shadow_tracing_distance"):
            out[k] = max(float(out.get(k, v)), float(v))
    bot = min(va["layer_bottom_altitude"], vb["layer_bottom_altitude"])
    top = max(va["layer_bottom_altitude"] + va["layer_height"], vb["layer_bottom_altitude"] + vb["layer_height"])
    out["layer_bottom_altitude"] = bot
    out["layer_height"] = top - bot
    scale = max(float(va["view_sample_count_scale"]), float(vb["view_sample_count_scale"]))
    grow = max((top - bot) / max(va["layer_height"], vb["layer_height"]), 1.0)
    out["view_sample_count_scale"] = min(scale * grow, SAMPLE_SCALE_MAX)
    return out


def lerp_val(a, b, w, key=""):
    """Blend two preset values by type: numbers linearly (a light's intensity in log space), lists and plain dicts per
    element, encoded snapshot values ({"__t": ...}) per element when both have the same type; anything else switches at
    w = 0.5."""
    if isinstance(a, bool) or isinstance(b, bool):
        return b if w >= 0.5 else a
    if isinstance(a, (int, float)) and isinstance(b, (int, float)):
        if key == "intensity" and a > 0.0 and b > 0.0:
            return math.exp(math.log(a) + (math.log(b) - math.log(a)) * w)
        return a + (b - a) * w
    if isinstance(a, list) and isinstance(b, list) and len(a) == len(b):
        out = []
        for x, y in zip(a, b):
            v = lerp_val(x, y, w)
            out.append(int(round(v)) if isinstance(x, int) and isinstance(y, int) else v)
        return out
    if isinstance(a, dict) and isinstance(b, dict):
        if "__t" in a or "__t" in b:
            if a.get("__t") == b.get("__t") and isinstance(a.get("v"), (list, dict)):
                return dict(a, v=lerp_val(a["v"], b["v"], w))
            return b if w >= 0.5 else a
        return {k: lerp_val(a.get(k, b.get(k)), b.get(k, a.get(k)), w, k) for k in sorted(set(a) | set(b))}
    return b if w >= 0.5 else a


def dome_state(a, b, intensity):
    """(dome present, star values) during a "full" transition with a night end: the dome exists below DOME_LUX and its
    StarIntensity rises (in log of the light) from 0 there to the night preset's value."""
    night = b if b.get("night_sky") else (a if a.get("night_sky") else None)
    if night is None or intensity is None or intensity >= DOME_LUX:
        return False, None
    i_night = float(night["components"][LIGHT]["intensity"])
    span = math.log(DOME_LUX) - math.log(i_night)
    k = (math.log(DOME_LUX) - math.log(max(float(intensity), 1.0e-9))) / span if span > 0.0 else 1.0
    stars = dict(night["night_sky"])
    stars["StarIntensity"] = night["night_sky"]["StarIntensity"] * ease(k)
    return True, stars


def look_trans(state, p, ppv_defaults, clouds_light):
    """The look during a transition at eased progress p (spec §4.5). "clouds" keeps the outgoing look."""
    tr = state["trans"]
    a = tr["from_look"]
    if tr["light"] == "clouds":
        return look_static(a, clouds_light)
    b = tr["to"]
    w = sub(p, LIGHT_WINDOW[0], LIGHT_WINDOW[1])
    comps = {}
    for s in sorted(set(a["components"]) | set(b["components"])):
        if s == CLOUD:
            continue
        va, vb = a["components"].get(s, {}), b["components"].get(s, {})
        comps[s] = {k: lerp_val(va.get(k, vb.get(k)), vb.get(k, va.get(k)), w, k) for k in sorted(set(va) | set(vb))}
    if LIGHT in comps:
        comps[LIGHT]["cast_shadows_on_clouds"] = bool(clouds_light)
    sun = [a["sun"][0] + (b["sun"][0] - a["sun"][0]) * w, a["sun"][1] + _arc(a["sun"][1], b["sun"][1]) * w]
    ppv = {}
    for k in sorted(set(a["ppv"]) | set(b["ppv"])):
        va = a["ppv"][k] if k in a["ppv"] else ppv_defaults.get(k, b["ppv"].get(k))
        vb = b["ppv"][k] if k in b["ppv"] else ppv_defaults.get(k, a["ppv"].get(k))
        ppv[k] = lerp_val(va, vb, w, k)
    dome, stars = dome_state(a, b, comps.get(LIGHT, {}).get("intensity"))
    return {"components": comps, "sun": sun, "ppv": ppv, "dome": dome, "stars": stars}


def progress(state, t):
    """Raw progress (0..1) of the running transition at simulated time t (independent of the playback speed)."""
    tr = state["trans"]
    return min(max((t - tr["t_start"]) / tr["dur"], 0.0), 1.0)


def check_target(state, name, names, duration_s, light):
    """Why a transition to `name` cannot start now (a reason string), or None."""
    if state["trans"] is not None:
        return "a transition is running"
    if name not in names:
        return "unknown preset %s" % name
    if name == state["slots"]["A"]["preset"]:
        return "%s is already the current cloud" % name
    if light not in ("full", "clouds"):
        return "light must be \"full\" or \"clouds\""
    if not duration_s >= MIN_TRANSITION_S:
        return "a transition needs at least %.0f simulated seconds" % MIN_TRANSITION_S
    return None


def check_seek(state):
    return "a transition is running" if state["trans"] is not None else None


def start_transition(state, resolved_b, t, duration_s, light="full"):
    why = check_target(state, resolved_b["name"], [resolved_b["name"]], duration_s, light)
    if why:
        raise ValueError(why)
    state["slots"]["B"] = new_slot(resolved_b, t, -float(duration_s))
    state["trans"] = {"to": resolved_b, "from_look": state["look"], "t_start": float(t), "dur": float(duration_s),
                      "light": light}
    return state


def finish_transition(state):
    """The incoming slot becomes slot A (its values are identical, so the frame does not change); a "full" transition
    also hands over the look."""
    tr = state["trans"]
    state["slots"]["A"] = state["slots"]["B"]
    state["slots"]["B"] = None
    if tr["light"] == "full":
        state["look"] = tr["to"]
    state["trans"] = None
    return state
```

```python
def _weather(reload=False):
    """cs_weather.py as a module (its bridge entry is guarded, so importing it runs no phase). Reloaded at phase entry,

def _same(a, b):
    try:
        return abs(float(a) - float(b)) <= 1.0e-6 * max(1.0, abs(float(a)), abs(float(b)))
    except (TypeError, ValueError):
        return a == b


def read_ppv_defaults():
    """The engine default of every managed post-process setting (what a setting falls back to when only one end of a
    transition overrides it), JSON-ish like the preset data."""
    s = unreal.PostProcessSettings()
    out = {}
    for key in R.managed_ppv():
        v = s.get_editor_property(key)
        if isinstance(v, unreal.Vector4):
            out[key] = [v.x, v.y, v.z, v.w]
        elif isinstance(v, unreal.LinearColor):
            out[key] = [v.r, v.g, v.b, v.a]
        elif isinstance(v, unreal.EnumBase):
            out[key] = v.name
        elif isinstance(v, bool):
            out[key] = v
        elif isinstance(v, (int, float)):
            out[key] = float(v)
        else:
            out[key] = v
    return out


class Director:

        self.cache = {}
        self.refs = {}
        self.handle = None
        self.mid = None
        self.dome_mid = None
        self.ticks = []
        self.error = None
        self.last_beat = 0.0

        self.job = None          # the clip being recorded (Task 10)

    def _find_refs(self):

        mid = unreal.KismetMaterialLibrary.create_dynamic_material_instance(cloud, unreal.load_asset(MATERIAL))
        cloud.set_editor_property("material", mid)

        look = M.look_static(r, self.state["slots"]["A"]["clouds_light"])
        for section, vals in look["components"].items():
            for prop, v in vals.items():
                self.cache[(section, prop)] = v
        for prop, v in r["components"].get(M.CLOUD, {}).items():
            self.cache[(M.CLOUD, prop)] = v
        self.cache["sun"] = [round(look["sun"][0], 6), round(look["sun"][1], 6)]
        self.cache["ppv"] = dict(look["ppv"])

        self.state = M.new_state(r, self.t)
        self.cache = {}
        self._prime(r)
        self.mid = self._make_mid()

        self.apply_frame()
        self.handle = unreal.register_slate_post_tick_callback(lib.guarded(self.tick))
        self.save_status()

    def write_mid(self, values):
        for name, v in values.items():
            key = ("mid", name)
            if key in self.cache and _same(self.cache[key], v):
                continue
            self.mid.set_scalar_parameter_value(name, float(v))
            self.cache[key] = v

    def write_prop(self, section, prop, value):
        """One component property: the Blueprint setter when the component has one and is not Static (verified by
        reading back, plan ruling R5), else set_editor_property."""
        key = (section, prop)
        if key in self.cache and self.cache[key] == value:
            return
        _actor, comp = self.refs.get(section, (None, None))
        if comp is None:
            return
        new = lib.value_for(comp, prop, value)
        done = False
        setter = getattr(comp, "set_" + prop, None)
        if setter is not None and comp.get_editor_property("mobility") != unreal.ComponentMobility.STATIC:
            try:
                setter(new)
                done = _same(comp.get_editor_property(prop), new) if isinstance(new, float) else True
            except Exception:
                done = False
        if not done:
            comp.set_editor_property(prop, new)
        self.cache[key] = value

    def write_vc(self, vc):
        for prop, v in vc.items():
            self.write_prop(M.CLOUD, prop, v)

    def write_ppv(self, values):
        if self.cache.get("ppv") == values:
            return
        ppv = self.refs.get("ppv")
        if ppv is None:
            return
        s = ppv.get_editor_property("settings")
        for prop in R.managed_ppv():
            s.set_editor_property("override_" + prop, prop in values)
        for prop, val in values.items():
            if prop == "auto_exposure_method":
                val = getattr(unreal.AutoExposureMethod, val)
            elif isinstance(val, list):
                val = unreal.Vector4(*val) if len(val) == 4 else unreal.LinearColor(*val)
            s.set_editor_property(prop, val)
        ppv.set_editor_property("settings", s)
        self.cache["ppv"] = dict(values)

    def write_dome(self, present, stars):
        """The night weathers' star dome (cs_weather._night_sky spawns / removes it). While it exists, its material is
        a MID so that StarIntensity can change every frame."""
        if not present:
            if self.cache.get("dome"):
                _weather()._night_sky(None)
                self.dome_mid = None
            self.cache["dome"] = False
            return
        if not self.cache.get("dome"):
            _weather()._night_sky(stars)
            smc = lib.find_label(NIGHT_LABEL).static_mesh_component
            self.dome_mid = unreal.KismetMaterialLibrary.create_dynamic_material_instance(smc, unreal.load_asset(NIGHT_MI))
            smc.set_material(0, self.dome_mid)
            self.cache["dome"] = True
            for k in [k for k in self.cache if isinstance(k, tuple) and k[0] == "dome"]:
                del self.cache[k]
        for k, v in stars.items():
            key = ("dome", k)
            if key in self.cache and _same(self.cache[key], v):
                continue
            self.dome_mid.set_scalar_parameter_value(k, float(v))
            self.cache[key] = v

    def write_look(self, look):
        for section, vals in look["components"].items():
            for prop, v in vals.items():
                self.write_prop(section, prop, v)
        sun = [round(float(look["sun"][0]), 6), round(float(look["sun"][1]), 6)]
        if self.cache.get("sun") != sun:
            actor, _comp = self.refs[M.LIGHT]
            actor.set_actor_rotation(lib.sun_rotation(sun[0], sun[1]), False)
            self.cache["sun"] = sun
        self.write_ppv(look["ppv"])
        self.write_dome(look["dome"], look["stars"])

    # --- frame / tick ------------------------------------------------------------------------------------------------
    def apply_frame(self):
        st = self.state
        if st["trans"] is not None and M.progress(st, self.t) >= 1.0:
            M.finish_transition(st)
        fr = M.frame(st, self.t, self.ppv_defaults)
        self.write_mid(fr["mid"])
        self.write_vc(fr["vc"])
        self.write_look(fr["look"])
        self.last_frame = {"t": round(fr["t"], 3), "p": fr["p"], "f": fr.get("f"), "g": fr.get("g")}

    def tick(self, dt):
        t0 = time.perf_counter()
        try:
            if self.job is not None:
                self.record_tick()
            else:
                if not self.paused:
                    self.t += float(dt) * self.speed
                self.apply_frame()
        except Exception as exc:
            self.error = "%s: %s" % (type(exc).__name__, exc)
            self.stop_tick()
            self.save_status("error")
            return
        self.ticks.append((time.perf_counter() - t0) * 1000.0)
        del self.ticks[:-100]
        if time.time() - self.last_beat > HEARTBEAT_S:
            self.save_status()

    def stop_tick(self):
        if self.handle is not None:
            unreal.unregister_slate_post_tick_callback(self.handle)
            self.handle = None

    def stop(self, static=False, reason="stop"):
        self.stop_tick()
        lib.cvar_set("r.VolumetricRenderTarget.Mode", STILL_MODE)
        out = {"stopped": reason, "t": round(self.t, 2)}
        if static and self.state is not None:
            tr = self.state["trans"]
            out["apply"] = _weather().phase_apply({"preset": tr["to"]["name"] if tr else self.state["slots"]["A"]["preset"]})
        self.save_status("stopped")
        if holder().director is self:
            holder().director = None
        return out

    def summary(self):
        st = self.state
        slots = {}
        if st is not None:
            for k in ("A", "B"):
                s = st["slots"][k]
                if s is not None:
                    adv = M.adv_km(s, self.t)
                    slots[k] = {"preset": s["preset"], "tau": round(self.t - s["tau0"], 1), "adv_km": round(adv, 1),
                                "adv_budget_km": round(M.ADV_BUDGET_KM - adv, 1)}
        tr = st["trans"] if st is not None else None
        ms = sorted(self.ticks)
        job = None if self.job is None else {k: self.job[k] for k in ("clip", "k", "n", "phase", "errors")}
        return {"t": round(self.t, 2), "speed": self.speed, "paused": self.paused, "slots": slots,

def _preflight():
    refused = lib.require_level()

        return refused
    if lib.shot_queue_busy():

def _need():
    d = current()
    if d is None:
        return None, {"refused": "the director is not running; call play first"}
    if d.handle is None:
        return None, {"refused": "the director's tick has stopped: %s" % d.error}
    return d, None

    d = current()
    return d.stop(reason=reason) if d is not None else None


def phase_play(args):
    """{"preset": name (default: the preset cs_weather.py applied last), "speed": 30, "t": 0}"""
    refused = _preflight()
    if refused:
        return refused
    stop_current("replaced by play")
    W = _weather(reload=True)
    name = args.get("preset") or lib.load_json(CURRENT, {}).get("preset") or "base"
    if name == "original":
        name = "base"

        return {"abort": "unknown preset %s" % name}
    if not float(args.get("speed", M.SPEED)) > 0.0:
        return {"abort": "speed must be > 0"}
    applied = W.phase_apply({"preset": name})
    if "abort" in applied or "refused" in applied:
        return applied
    d = Director(args.get("speed", M.SPEED))
    d.start(name, float(args.get("t", 0.0)))
    holder().director = d
    return {"play": name, "speed": d.speed, "t": d.t, "status": STATUS}

        return err
```

```python
def camera_pose(c):
    """A camera entry of cs_weather_presets.CAMERAS ("rot" or "target") as loc / rot [pitch, yaw, roll] / fov / aspect /
    res."""
    if "rot" in c:
        rot = [float(c["rot"][0]), float(c["rot"][1]), 0.0]
    else:
        dx, dy, dz = (c["target"][i] - c["loc"][i] for i in range(3))
        rot = [math.degrees(math.atan2(dz, math.hypot(dx, dy))), math.degrees(math.atan2(dy, dx)), 0.0]
    return {"loc": [float(x) for x in c["loc"]], "rot": rot, "fov": float(c["fov"]), "aspect": float(c["aspect"]),
            "res": list(c["res"])}


def camera_at(ca, cb, w):
    """Blend two cameras by w: location and FOV linearly, pitch and yaw separately (yaw the short way, no roll). One
    output size per clip: aspect and resolution stay the first camera's."""
    a, b = camera_pose(ca), camera_pose(cb)
    return {"loc": [a["loc"][i] + (b["loc"][i] - a["loc"][i]) * w for i in range(3)],
            "rot": [a["rot"][0] + (b["rot"][0] - a["rot"][0]) * w, a["rot"][1] + _arc(a["rot"][1], b["rot"][1]) * w,

def clip_frames(clip):
    """Frame timing of a clip: {"n", "dt" (simulated s per frame), "times" (stills), "t_start" / "dur" / "hold_frames" /
    "speed" (transitions)}. A transition clip plays the start preset for `hold` seconds, then the transition, then the
    target for `hold` seconds; its speed follows from the transition's simulated length."""
    if clip["kind"] == "stills":
        return {"n": len(clip["times"]), "dt": None, "times": list(clip["times"]), "t_start": None, "dur": None}
    n = int(round(clip["seconds"] * clip["fps"]))
    if clip["kind"] == "preset":
        return {"n": n, "dt": clip["speed"] / clip["fps"], "times": None, "t_start": None, "dur": None}
    wall = clip["seconds"] - 2.0 * clip["hold"]
    dur = clip["minutes"] * 60.0
    speed = dur / wall
    dt = speed / clip["fps"]
    hold = int(round(clip["hold"] * clip["fps"]))
    return {"n": n, "dt": dt, "times": None, "t_start": hold * dt, "dur": dur, "hold_frames": hold, "speed": speed}
```

```python
# motion_check.py -- jumps in a recorded clip (spec §6.2). Every frame is box-downscaled 8x in luma (the clouds' sampling
# noise averages out) and compared with the one before. A frame whose change exceeds FACTOR x the clip's median change
# (the median over every frame pair, floored at FLOOR levels) is a jump.
#   C:\Python314\python.exe -P -E Tools/cs_weather/motion_check.py <clip> [--from 30] [--to 451] [--factor 3]
#   -> Saved/Reports/cs_cloud_motion/checks/<clip>.json and <clip>.png (the change per frame); exit 1 on a jump
import argparse
import glob
import json
import os
import statistics
import sys

import numpy as np
from PIL import Image, ImageDraw

ROOT = os.path.abspath(os.path.join(os.path.dirname(__file__), "..", ".."))
BASE = os.path.join(ROOT, "Saved", "Reports", "cs_cloud_motion")
FLOOR = 0.05
W = np.array([0.2126, 0.7152, 0.0722], dtype=np.float32)


def luma8(path):
    a = np.asarray(Image.open(path).convert("RGB"), dtype=np.float32) @ W
    h, w = a.shape[0] // 8 * 8, a.shape[1] // 8 * 8
    return a[:h, :w].reshape(h // 8, 8, w // 8, 8).mean(axis=(1, 3))


def diffs(paths):
    """d[k] = mean |luma8(frame k) - luma8(frame k-1)|; d[0] = 0."""
    out, prev = [0.0], luma8(paths[0])
    for p in paths[1:]:
        cur = luma8(p)
        out.append(float(np.abs(cur - prev).mean()))
        prev = cur
    return out


def jumps(d, lo, hi, factor):
    """Frames k in [lo, hi) whose change exceeds factor x the median change of the whole clip."""
    med = max(statistics.median(d[1:]), FLOOR) if len(d) > 1 else FLOOR
    return [k for k in range(max(lo, 1), min(hi, len(d))) if d[k] > factor * med]


def plot(d, flagged, lo, hi, path):
    w, h = 900, 240
    im = Image.new("RGB", (w, h), (250, 250, 250))
    dr = ImageDraw.Draw(im)
    top = max(d) or 1.0

    def x(k):
        return 20 + (w - 40) * k / max(len(d) - 1, 1)

    def y(v):
        return h - 20 - (h - 40) * v / top

    dr.rectangle([x(lo), 10, x(max(hi - 1, lo)), h - 20], fill=(230, 238, 250))
    dr.line([(x(k), y(v)) for k, v in enumerate(d)], fill=(40, 90, 160), width=2)
    for k in flagged:
        dr.ellipse([x(k) - 4, y(d[k]) - 4, x(k) + 4, y(d[k]) + 4], outline=(200, 40, 40), width=2)
    im.save(path)


def main():
    sys.stdout.reconfigure(encoding="utf-8")
    ap = argparse.ArgumentParser()
    ap.add_argument("clip")
    ap.add_argument("--from", dest="lo", type=int, default=1)
    ap.add_argument("--to", dest="hi", type=int, default=10 ** 9)
    ap.add_argument("--factor", type=float, default=3.0)
    a = ap.parse_args()
    paths = sorted(glob.glob(os.path.join(BASE, "frames", a.clip, "f_*.png")))
    if len(paths) < 3:
        print("%s: %d frames" % (a.clip, len(paths)))
        return 2
    d = diffs(paths)
    flagged = jumps(d, a.lo, a.hi, a.factor)
    out = os.path.join(BASE, "checks")
    os.makedirs(out, exist_ok=True)
    res = {"clip": a.clip, "frames": len(paths), "median": round(statistics.median(d[1:]), 4), "max": round(max(d), 4),
           "range": [max(a.lo, 1), min(a.hi, len(d))], "factor": a.factor, "jumps": flagged,
           "d": [round(v, 4) for v in d]}
    json.dump(res, open(os.path.join(out, a.clip + ".json"), "w", encoding="utf-8"), indent=1)
    plot(d, flagged, max(a.lo, 1), min(a.hi, len(d)), os.path.join(out, a.clip + ".png"))
    print({k: res[k] for k in ("clip", "frames", "median", "max", "jumps")})
    return 1 if flagged else 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
        x += t.width + 4
    strip.save(os.path.join(CLIPS, clip + "_strip.jpg"), quality=85)
```

```python
def phase_record(args):
    """{"clips": [names] | "all" | "stills", "seconds": s (motion clips only: a quick test), "max_commit_gb": 64}
    Records the clips one after another from the tick. Frames already on disk are kept, so a stopped run resumes."""
    refused = _preflight()
    if refused:
        return refused
    known = {c["clip"]: c for c in M.clip_list(P) + M.stills_list(P)}
    sel = args.get("clips")

        names = [c["clip"] for c in M.clip_list(P)]
    elif sel == "stills":
        names = [c["clip"] for c in M.stills_list(P)]
    else:
        names = list(sel or [])
    unknown = [n for n in names if n not in known]
    if unknown or not names:
        return {"abort": ("unknown clips %s" % unknown) if unknown else "no clips given"}
    queue = []
    for n in names:
        c = dict(known[n])
        if "seconds" in args and c["kind"] == "preset":

    d.queue = queue
    d.max_commit = float(args.get("max_commit_gb", 64.0))
    holder().director = d
    d.next_clip()
    d.handle = unreal.register_slate_post_tick_callback(lib.guarded(d.tick))
    d.save_status()
    return {"record": names, "status": STATUS}
```
