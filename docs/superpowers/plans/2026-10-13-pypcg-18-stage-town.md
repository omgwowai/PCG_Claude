# PyPCG: 18 City Sample stage graphs as Python, and an 18-stage town — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each of the 18 official City Sample stage graphs becomes one curated `.py` file that rebuilds a graph asset with zero structural differences from the official one; a new 1 km town level is then generated by those graphs, stage by stage, in the Feishu doc's 18-step order.

**Architecture:** Four layers. (1) A small C++ editor plugin `PyPCGTools` exposes the graph fields Python reflection cannot reach, plus one exporter that writes a whole graph as JSON IR. (2) A pure-Python package `pypcg` (DSL → IR, comparator, code generator), tested offline with pytest. (3) Editor-side builder and entry scripts that write IR into assets and verify them (L2) and compare generation results (L3). (4) A town profile + layout that bind the same stage files to a template-copied level.

**Tech Stack:** UE 5.8.2 source build (`E:\UnrealEngine`), C++ (UBT via `Build.bat`), editor Python 3.11 through the `run_unreal_script` bridge (127.0.0.1:8777), pytest on `C:\Python314\python.exe` (Python 3.14), PCG + PCGPrimitives + CitySamplePCG content.

**Spec:** `docs/superpowers/specs/2026-10-13-pypcg-18-stage-town-design.md` (commit `ea220be`). Source analysis: Feishu doc https://omgwowai.feishu.cn/wiki/DSSwwgvfuicQblkBLGYcvpE0nab, local copy `Saved/feishu/pcg_doc.md` (not in git; re-fetch with `lark-cli docs +fetch --as user --doc <url> --doc-format markdown` if missing). ## Rulings (where the spec is silent or wrong)

- **R1 Stage numbering follows the Feishu doc**, not the 09-24 census order the spec's §5.5 used. The user asked for "the 18 steps"; the doc defines them. So §5.5's "第 13 步建筑含 TL" becomes **step 11 (Buildings)**, and the stage files are `s11_buildings`, `s12_rooftops`, `s13_leftover_lots`, `s14_parkings`. Dependencies allow either order (LeftOverLots and Parkings do not read Buildings).
- **R2 Layout reuses the official positions.** Spec §3.3 rule 10 said "auto-layout by step + generated step boxes". But §3.5 requires comment-box membership to match, and the 158 official boxes are laminar only at official positions (measured: 0 empty, 0 overlapping pairs). So the builder copies positions and boxes from the official IR through the comparator's node bijection; unmatched (new) nodes are auto-placed; no generated step boxes. Positions still never appear in the `.py`.
- **R3 C++ functions adjusted, still 9.** `SetPropertyText` → `SetPropertiesJson` (exact floats, nested structs, instanced subobjects in one call). `SetSubgraphParameter` → `SetInstanceParameter(UPCGGraphInstance*)` so component instances use it too. The debug `ExportObjectProperties` is replaced by `ExportInstanceOverrides`.
- **R4 L3 runs on the codegen drafts (Task 8), before curation.** Curation must keep L1 = 0, which means an identical structure, so L3 is not repeated; each curated graph is rebuilt and re-checked with L2.
- **R5 Parameter categories/tooltips** are written as desc metadata and turned into the editor hierarchy by PCG's own `TransferPropertyBagMetadataIntoHierarchy`; the comparator ignores the `Category`/`ToolTip` keys in raw desc metadata and compares the hierarchy result.
- **R6 FText** (graph description, tooltips) compares by display string; localization keys are not preserved.
- **R7 JSON value convention** `{"v": <value>}` for every single-value argument.
- **R8 One actor per role, 13 roles.** `g.ref([...])` takes a list for nodes that read several actors.
- **R9 Final regression** checks that no official asset changed (mtime/size baseline taken in Task 1), plus the 3×3 and TL showcase counts by relaunching into their levels.

## Review Focus

1. **An AI edits a stage file and misspells a pin or parameter** → must fail before anything is built, naming the real pins/params. Test owner: Task 5 (`test_unknown_input_pin_lists_real_pins`, `test_unknown_param_lists_params`).
2. **A subgraph override whose value equals the subgraph default** (official graphs have many) must stay marked overridden after a build. Test owner: Task 1 (`PyPCGTools.InstanceParameters`, the AbsoluteOffset case) and Task 7 (L2 over all 18).
3. **Symmetric nodes** (identical untitled reroutes feeding one Gather) must still pair in the comparator. Test owner: Task 3 (`test_symmetric_reroutes_pair`).
4. **A town stage silently reading the demo level's data** (spec F8) must fail its stage. Test owner: Task 20 (`test_bbox_outside_town_fails`).
5. **A float that does not survive 6-decimal text** (`-1820.4246063232422`) must round-trip exactly through extract → build → extract. Test owner: Task 1 (`PyPCGTools.InstanceParameters`, `PyPCGTools.PinDefaults`) and Task 3 (`test_int_and_float_compare_by_value`).

**Files:**

**Interfaces — Produces** (Python names, used by every later editor task):
- `unreal.PyPCGToolsLibrary.export_graph_ir(graph) -> str` (IR JSON, schema below)
- `export_instance_overrides(instance) -> str` (`{"<param>": value}`)
- `set_properties_json(obj, json_str) -> str`
- `set_instance_parameter(instance, name, '{"v": ...}') -> str`
- `set_pin_default_value(settings, pin_index, type_name, '{"v": ...}', has_value, activated) -> str`
- `set_graph_user_parameters(graph, '{"params": [...]}') -> str`
- `bind_user_parameter_getter(getter_settings, name) -> str`
- `set_node_comment(node, comment, bubble_visible, bubble_pinned) -> str`
- `set_graph_comment_boxes(graph, '{"boxes": [...]}') -> str`
- Every write returns `""` on success, else the error text.

IR schema 1 (one JSON object):
```
{"schema":1, "graph":"<object path>", "graph_props":{non-default graph UPROPERTYs},
 "params":[{"name","type","container","type_object","meta":{k:v},"value",
            "category":"A|B","hier_meta":{"Values":[...]}|null}],
 "comment_boxes":[FPCGGraphCommentNodeData as JSON, no GUID],
 "nodes":[{"name","class","title","title_color"?:[r,g,b,a],"comment","bubble_visible",
           "bubble_pinned","pos":[x,y],"settings":{non-default vs class CDO},
           "getter_param":"", "subgraph"?:"<path>", "overrides"?:{name:value},
           "pin_defaults":[{"index","prop","activated","type"|null,"value"|null}],
           "inputs":[{"label","edges":[[src_node, src_pin], ...]}], "outputs":[labels]}]}
```
`settings` never contains `SubgraphInstance`, `SubgraphOverride`, `CachedOverridableParams`, `DefaultValues`, or (on getters) `PropertyGuid`/`PropertyName`. A value the JSON converter cannot express is the string `"$text:<UE text>"`.

- [ ] **Step 1: Record the official-asset baseline** (ruling R9). Create `Tools/pypcg/baseline.py`:

```python
#!/usr/bin/env python
"""Record or check mtime+size of the official CitySample assets this work must not touch.

    python Tools/pypcg/baseline.py record    # writes Tools/data/pypcg_official_baseline.json
    python Tools/pypcg/baseline.py check     # exit 1 and list every changed file
"""
import json
import os
import sys

REPO = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
OUT = os.path.join(REPO, "Tools", "data", "pypcg_official_baseline.json")
ROOTS = [os.path.join(REPO, "Plugins", "CitySamplePCG", "Content", "Levels"),
         os.path.join(REPO, "Plugins", "CitySamplePCG", "Content", "PCG"),
         os.path.join(REPO, "Plugins", "CitySamplePCG", "Content", "__ExternalActors__")]


def scan():
    out = {}
    for root in ROOTS:
        for d, _, files in os.walk(root):
            for f in files:
                if f.endswith((".uasset", ".umap")):
                    p = os.path.join(d, f)
                    st = os.stat(p)
                    out[os.path.relpath(p, REPO).replace("\\", "/")] = [int(st.st_mtime), st.st_size]
    return out


def main(argv):
    if argv[1:] == ["record"]:
        os.makedirs(os.path.dirname(OUT), exist_ok=True)
        with open(OUT, "w", encoding="utf-8") as fh:
            json.dump(scan(), fh, indent=0, sort_keys=True)
        print("recorded", OUT)
        return 0
    if argv[1:] == ["check"]:
        with open(OUT, encoding="utf-8") as fh:
            base = json.load(fh)
        now = scan()
        changed = sorted(k for k in set(base) | set(now) if base.get(k) != now.get(k))
        for k in changed:
            print("CHANGED", k, base.get(k), now.get(k))
        print("%d files, %d changed" % (len(now), len(changed)))
        return 1 if changed else 0
    print(__doc__)
    return 2


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

- [ ] **Step 4: Write the implementation** `Private/PyPCGToolsLibrary.cpp`. Private PCG members are read by reflection (`FindFProperty` by name), never by C++ member access, so no engine change is needed; writes use PCG's public API wherever one exists.

```cpp
#include "PyPCGToolsLibrary.h"

#include "Dom/JsonObject.h"
#include "Dom/JsonValue.h"
#include "Editor/IPCGEditorModule.h"
#include "Editor/PCGGraphComment.h"
#include "Elements/Metadata/PCGMetadataOpElementBase.h"
#include "Elements/PCGUserParameterGet.h"
#include "Helpers/PCGPropertyHelpers.h"
#include "JsonObjectConverter.h"
#include "Metadata/PCGDefaultValueInterface.h"
#include "Metadata/PCGMetadataCommon.h"
#include "PCGEdge.h"
#include "PCGGraph.h"
#include "PCGNode.h"
#include "PCGPin.h"
#include "PCGSettings.h"
#include "PCGSubgraph.h"
#include "Policies/CondensedJsonPrintPolicy.h"
#include "Serialization/JsonReader.h"
#include "Serialization/JsonSerializer.h"
#include "Serialization/JsonWriter.h"
#include "StructUtils/PropertyBag.h"
#include "UObject/UnrealType.h"

#include UE_INLINE_GENERATED_CPP_BY_NAME(PyPCGToolsLibrary)

namespace PyPCGTools::Private
{
	// Transient and deprecated properties are not part of a graph's saved state.
	constexpr int64 SkipFlags = CPF_Transient | CPF_Deprecated;
	constexpr EJsonObjectConversionFlags ConversionFlags = EJsonObjectConversionFlags::SkipStandardizeCase;
	// A value the JSON converter cannot express travels as UE property text behind this prefix.
	const FString TextPrefix = TEXT("$text:");

	using FHierarchyEntry = TPair<FString, TSharedPtr<FJsonValue>>;

	bool IsProtected(const UObject* Object, FString& OutError)
	{
		const FString Package = Object->GetOutermost()->GetName();
		if (Package.StartsWith(TEXT("/Engine/Transient")))
		{
			return false;
		}
		for (const TCHAR* Root : {TEXT("/CitySamplePCG/"), TEXT("/PCGPrimitives"), TEXT("/Engine/")})
		{
			if (Package.StartsWith(Root))
			{
				OutError = FString::Printf(TEXT("refused: %s is under the protected mount %s"), *Package, Root);
				return true;
			}
		}
		return false;
	}

	FString Write(const TSharedRef<FJsonObject>& Object)
	{
		FString Out;
		const TSharedRef<TJsonWriter<TCHAR, TCondensedJsonPrintPolicy<TCHAR>>> Writer =
			TJsonWriterFactory<TCHAR, TCondensedJsonPrintPolicy<TCHAR>>::Create(&Out);
		FJsonSerializer::Serialize(Object, Writer);
		return Out;
	}

	FString WriteValue(const TSharedPtr<FJsonValue>& Value)
	{
		const TSharedRef<FJsonObject> Wrap = MakeShared<FJsonObject>();
		Wrap->SetField(TEXT("v"), Value.IsValid() ? Value : MakeShared<FJsonValueNull>());
		return Write(Wrap);
	}

	TSharedPtr<FJsonObject> ParseObject(const FString& Text, FString& OutError)
	{
		TSharedPtr<FJsonObject> Object;
		const TSharedRef<TJsonReader<TCHAR>> Reader = TJsonReaderFactory<TCHAR>::Create(Text);
		if (!FJsonSerializer::Deserialize(Reader, Object) || !Object.IsValid())
		{
			OutError = FString::Printf(TEXT("bad JSON: %s"), *Text.Left(200));
			return nullptr;
		}
		return Object;
	}

	TSharedPtr<FJsonValue> NumberArray(std::initializer_list<double> Values)
	{
		TArray<TSharedPtr<FJsonValue>> Out;
		for (const double Value : Values)
		{
			Out.Add(MakeShared<FJsonValueNumber>(Value));
		}
		return MakeShared<FJsonValueArray>(Out);
	}

	TSharedPtr<FJsonValue> PropertyToJson(FProperty* Property, const void* Value, UObject* Owner)
	{
		TSharedPtr<FJsonValue> Json = FJsonObjectConverter::UPropertyToJsonValue(Property, Value, 0, SkipFlags, nullptr, nullptr, ConversionFlags);
		if (!Json.IsValid())
		{
			FString Text;
			Property->ExportTextItem_Direct(Text, Value, nullptr, Owner, PPF_None);
			Json = MakeShared<FJsonValueString>(TextPrefix + Text);
		}
		return Json;
	}

	bool JsonToProperty(const TSharedPtr<FJsonValue>& Value, FProperty* Property, void* Data, UObject* Owner, FString& OutError)
	{
		FString Text;
		if (Value.IsValid() && Value->Type == EJson::String && Value->TryGetString(Text) && Text.StartsWith(TextPrefix))
		{
			if (!Property->ImportText_Direct(*Text.Mid(TextPrefix.Len()), Data, Owner, PPF_None))
			{
				OutError = FString::Printf(TEXT("%s: cannot import text %s"), *Property->GetName(), *Text.Left(120));
				return false;
			}
			return true;
		}
		FText Fail;
		if (!FJsonObjectConverter::JsonValueToUProperty(Value, Property, Data, 0, 0, false, &Fail))
		{
			OutError = FString::Printf(TEXT("%s: %s"), *Property->GetName(), *Fail.ToString());
			return false;
		}
		return true;
	}

	TSharedRef<FJsonObject> ObjectToJson(UObject* Object, const TSet<FString>& Strip)
	{
		const TSharedRef<FJsonObject> Out = MakeShared<FJsonObject>();
		for (TFieldIterator<FProperty> It(Object->GetClass()); It; ++It)
		{
			FProperty* Property = *It;
			const FString Name = Property->GetName();
			if (Property->HasAnyPropertyFlags(SkipFlags) || Strip.Contains(Name))
			{
				continue;
			}
			Out->SetField(Name, PropertyToJson(Property, Property->ContainerPtrToValuePtr<void>(Object), Object));
		}
		return Out;
	}

	// Properties whose JSON differs from the class default object.
	TSharedRef<FJsonObject> NonDefault(UObject* Object, const TSet<FString>& Strip)
	{
		const TSharedRef<FJsonObject> Full = ObjectToJson(Object, Strip);
		const TSharedRef<FJsonObject> Default = ObjectToJson(Object->GetClass()->GetDefaultObject(), Strip);
		const TSharedRef<FJsonObject> Out = MakeShared<FJsonObject>();
		for (const auto& Field : Full->Values)
		{
			const TSharedPtr<FJsonValue>* Base = Default->Values.Find(Field.Key);
			if (!Base || WriteValue(*Base) != WriteValue(Field.Value))
			{
				Out->SetField(Field.Key, Field.Value);
			}
		}
		return Out;
	}

	void RefreshNode(UObject* Object)
	{
		Object->PostEditChange();
		if (UPCGNode* Node = Cast<UPCGNode>(Object->GetOuter()))
		{
			Node->UpdateAfterSettingsChangeDuringCreation();
		}
	}

	// UPCGMetadataSettingsBase::DefaultValues is private; reach its bag and activation set by reflection.
	FInstancedPropertyBag* DefaultValueBag(UObject* Settings, TSet<FName>** OutActivated)
	{
		*OutActivated = nullptr;
		const FStructProperty* Container = FindFProperty<FStructProperty>(Settings->GetClass(), TEXT("DefaultValues"));
		if (!Container)
		{
			return nullptr;
		}
		void* Data = Container->ContainerPtrToValuePtr<void>(Settings);
		if (const FSetProperty* Activated = FindFProperty<FSetProperty>(Container->Struct, TEXT("ActivatedProperties")))
		{
			*OutActivated = Activated->ContainerPtrToValuePtr<TSet<FName>>(Data);
		}
		const FStructProperty* Bag = FindFProperty<FStructProperty>(Container->Struct, TEXT("PropertyBag"));
		return Bag ? Bag->ContainerPtrToValuePtr<FInstancedPropertyBag>(Data) : nullptr;
	}

	TArray<TSharedPtr<FJsonValue>> ExportPinDefaults(UPCGSettings* Settings)
	{
		TArray<TSharedPtr<FJsonValue>> Out;
		TSet<FName>* Activated = nullptr;
		FInstancedPropertyBag* Bag = DefaultValueBag(Settings, &Activated);
		TSet<FName> Names;
		if (Activated)
		{
			Names.Append(*Activated);
		}
		if (const UPropertyBag* BagStruct = Bag ? Bag->GetPropertyBagStruct() : nullptr)
		{
			for (const FPropertyBagPropertyDesc& Desc : BagStruct->GetPropertyDescs())
			{
				Names.Add(Desc.Name);
			}
		}
		TArray<FName> Sorted = Names.Array();
		Sorted.Sort(FNameLexicalLess());
		for (const FName Name : Sorted)
		{
			const FString Text = Name.ToString();
			if (!Text.StartsWith(TEXT("DefaultValue")))
			{
				continue;
			}
			const TSharedRef<FJsonObject> Entry = MakeShared<FJsonObject>();
			Entry->SetNumberField(TEXT("index"), FCString::Atoi(*Text.Mid(12)) - 1);
			Entry->SetStringField(TEXT("prop"), Text);
			Entry->SetBoolField(TEXT("activated"), Activated && Activated->Contains(Name));
			const FPropertyBagPropertyDesc* Desc = Bag ? Bag->FindPropertyDescByName(Name) : nullptr;
			if (Desc && Desc->CachedProperty)
			{
				const EPCGMetadataTypes Type = PCGPropertyHelpers::GetMetadataTypeFromProperty(Desc->CachedProperty);
				Entry->SetStringField(TEXT("type"), StaticEnum<EPCGMetadataTypes>()->GetNameStringByValue(static_cast<int64>(Type)));
				const void* Value = Desc->CachedProperty->ContainerPtrToValuePtr<void>(Bag->GetValue().GetMemory());
				Entry->SetField(TEXT("value"), PropertyToJson(Desc->CachedProperty, Value, Settings));
			}
			else
			{
				Entry->SetField(TEXT("type"), MakeShared<FJsonValueNull>());
				Entry->SetField(TEXT("value"), MakeShared<FJsonValueNull>());
			}
			Out.Add(MakeShared<FJsonValueObject>(Entry));
		}
		return Out;
	}

	TSharedRef<FJsonObject> ExportOverrides(UPCGGraphInstance* Instance)
	{
		const TSharedRef<FJsonObject> Out = MakeShared<FJsonObject>();
		const FInstancedPropertyBag& Bag = Instance->ParametersOverrides.Parameters;
		const UPropertyBag* BagStruct = Bag.GetPropertyBagStruct();
		if (!BagStruct)
		{
			return Out;
		}
		for (const FPropertyBagPropertyDesc& Desc : BagStruct->GetPropertyDescs())
		{
			if (Desc.CachedProperty && Instance->IsPropertyOverridden(Desc.CachedProperty))
			{
				const void* Value = Desc.CachedProperty->ContainerPtrToValuePtr<void>(Bag.GetValue().GetMemory());
				Out->SetField(Desc.Name.ToString(), PropertyToJson(Desc.CachedProperty, Value, Instance));
			}
		}
		return Out;
	}

	// The parameter hierarchy uses StructUtilsEditor / DataHierarchyEditor classes whose members are not
	// exported; walk it generically by property name.
	void CollectHierarchy(UObject* Element, const FString& Chain, TMap<FGuid, FHierarchyEntry>& Out)
	{
		if (!Element)
		{
			return;
		}
		UClass* Class = Element->GetClass();
		FString Here = Chain;
		if (const FNameProperty* Category = FindFProperty<FNameProperty>(Class, TEXT("Category")))
		{
			const FString Name = Category->GetPropertyValue_InContainer(Element).ToString();
			Here = Chain.IsEmpty() ? Name : Chain + TEXT("|") + Name;
		}
		if (FStructProperty* Metadata = FindFProperty<FStructProperty>(Class, TEXT("PropertyMetadata")))
		{
			const FStructProperty* Identity = FindFProperty<FStructProperty>(Class, TEXT("Identity"));
			const FArrayProperty* Guids = Identity ? FindFProperty<FArrayProperty>(Identity->Struct, TEXT("Guids")) : nullptr;
			if (Guids)
			{
				FScriptArrayHelper Helper(Guids, Guids->ContainerPtrToValuePtr<void>(Identity->ContainerPtrToValuePtr<void>(Element)));
				if (Helper.Num() > 0)
				{
					const FGuid Id = *reinterpret_cast<const FGuid*>(Helper.GetRawPtr(0));
					Out.Add(Id, FHierarchyEntry(Chain, PropertyToJson(Metadata, Metadata->ContainerPtrToValuePtr<void>(Element), Element)));
				}
			}
		}
		if (const FArrayProperty* Children = FindFProperty<FArrayProperty>(Class, TEXT("Children")))
		{
			const FObjectPropertyBase* Inner = CastField<FObjectPropertyBase>(Children->Inner);
			FScriptArrayHelper Helper(Children, Children->ContainerPtrToValuePtr<void>(Element));
			for (int32 Index = 0; Inner && Index < Helper.Num(); ++Index)
			{
				CollectHierarchy(Inner->GetObjectPropertyValue(Helper.GetRawPtr(Index)), Here, Out);
			}
		}
	}

	void ClearChildren(UObject* Element)
	{
		if (const FArrayProperty* Children = FindFProperty<FArrayProperty>(Element->GetClass(), TEXT("Children")))
		{
			Element->Modify();
			FScriptArrayHelper Helper(Children, Children->ContainerPtrToValuePtr<void>(Element));
			Helper.EmptyValues();
		}
	}

	TArray<TSharedPtr<FJsonValue>> ExportParams(UPCGGraph* Graph)
	{
		TArray<TSharedPtr<FJsonValue>> Out;
		const FInstancedPropertyBag* Bag = Graph->GetUserParametersStruct();
		const UPropertyBag* BagStruct = Bag ? Bag->GetPropertyBagStruct() : nullptr;
		if (!BagStruct)
		{
			return Out;
		}
		TMap<FGuid, FHierarchyEntry> Hierarchy;
		CollectHierarchy(Graph->GetUserParameterHierarchyRoot(), FString(), Hierarchy);
		for (const FPropertyBagPropertyDesc& Desc : BagStruct->GetPropertyDescs())
		{
			const TSharedRef<FJsonObject> Param = MakeShared<FJsonObject>();
			Param->SetStringField(TEXT("name"), Desc.Name.ToString());
			Param->SetStringField(TEXT("type"), StaticEnum<EPropertyBagPropertyType>()->GetNameStringByValue(static_cast<int64>(Desc.ValueType)));
			Param->SetStringField(TEXT("container"), StaticEnum<EPropertyBagContainerType>()->GetNameStringByValue(static_cast<int64>(Desc.ContainerTypes.GetFirstContainerType())));
			Param->SetStringField(TEXT("type_object"), Desc.ValueTypeObject ? Desc.ValueTypeObject->GetPathName() : FString());
			const TSharedRef<FJsonObject> Meta = MakeShared<FJsonObject>();
#if WITH_EDITORONLY_DATA
			for (const FPropertyBagPropertyDescMetaData& Entry : Desc.MetaData)
			{
				Meta->SetStringField(Entry.Key.ToString(), Entry.Value);
			}
#endif
			Param->SetObjectField(TEXT("meta"), Meta);
			const void* Value = Desc.CachedProperty->ContainerPtrToValuePtr<void>(Bag->GetValue().GetMemory());
			Param->SetField(TEXT("value"), PropertyToJson(Desc.CachedProperty, Value, Graph));
			if (const FHierarchyEntry* Entry = Hierarchy.Find(Desc.ID))
			{
				Param->SetStringField(TEXT("category"), Entry->Key);
				Param->SetField(TEXT("hier_meta"), Entry->Value);
			}
			else
			{
				Param->SetStringField(TEXT("category"), FString());
				Param->SetField(TEXT("hier_meta"), MakeShared<FJsonValueNull>());
			}
			Out.Add(MakeShared<FJsonValueObject>(Param));
		}
		return Out;
	}

	// FPCGGraphCommentNodeData is not exported from PCG; find its reflection data by path.
	UScriptStruct* CommentStruct()
	{
		return FindObject<UScriptStruct>(nullptr, TEXT("/Script/PCG.PCGGraphCommentNodeData"));
	}

	TArray<TSharedPtr<FJsonValue>> ExportBoxes(UPCGGraph* Graph)
	{
		TArray<TSharedPtr<FJsonValue>> Out;
#if WITH_EDITOR
		UScriptStruct* Struct = CommentStruct();
		if (!Struct)
		{
			return Out;
		}
		for (const FPCGGraphCommentNodeData& Box : Graph->GetCommentNodes())
		{
			const TSharedRef<FJsonObject> Json = MakeShared<FJsonObject>();
			FJsonObjectConverter::UStructToJsonObject(Struct, &Box, Json, 0, SkipFlags, nullptr, ConversionFlags);
			Json->RemoveField(TEXT("GUID"));
			Out.Add(MakeShared<FJsonValueObject>(Json));
		}
#endif
		return Out;
	}

	FString ResolveGetter(const UPCGGraph* Graph, const UPCGUserParameterGetSettings* Getter)
	{
		const FInstancedPropertyBag* Bag = Graph->GetUserParametersStruct();
		const FPropertyBagPropertyDesc* Desc = Bag ? Bag->FindPropertyDescByID(Getter->PropertyGuid) : nullptr;
		return Desc ? Desc->Name.ToString() : TEXT("!unbound:") + Getter->PropertyName.ToString();
	}

	TSharedRef<FJsonObject> ExportNode(UPCGGraph* Graph, UPCGNode* Node)
	{
		const TSharedRef<FJsonObject> Out = MakeShared<FJsonObject>();
		UPCGSettings* Settings = Node->GetSettings();
		Out->SetStringField(TEXT("name"), Node->GetName());
		Out->SetStringField(TEXT("class"), Settings ? Settings->GetClass()->GetName() : FString());
		Out->SetStringField(TEXT("title"), Node->NodeTitle.IsNone() ? FString() : Node->NodeTitle.ToString());
#if WITH_EDITORONLY_DATA
		const FLinearColor Color = Node->NodeTitleColor;
		if (!Color.Equals(FLinearColor::White, 0.0f))
		{
			Out->SetField(TEXT("title_color"), NumberArray({Color.R, Color.G, Color.B, Color.A}));
		}
		Out->SetStringField(TEXT("comment"), Node->NodeComment);
		Out->SetBoolField(TEXT("bubble_visible"), Node->bCommentBubbleVisible != 0);
		Out->SetBoolField(TEXT("bubble_pinned"), Node->bCommentBubblePinned != 0);
		Out->SetField(TEXT("pos"), NumberArray({static_cast<double>(Node->PositionX), static_cast<double>(Node->PositionY)}));
#endif
		TSet<FString> Strip = {TEXT("SubgraphInstance"), TEXT("SubgraphOverride"), TEXT("CachedOverridableParams"), TEXT("DefaultValues")};
		FString GetterParam;
		if (const UPCGUserParameterGetSettings* Getter = Cast<UPCGUserParameterGetSettings>(Settings))
		{
			Strip.Add(TEXT("PropertyGuid"));
			Strip.Add(TEXT("PropertyName"));
			GetterParam = ResolveGetter(Graph, Getter);
		}
		Out->SetObjectField(TEXT("settings"), Settings ? NonDefault(Settings, Strip) : MakeShared<FJsonObject>());
		Out->SetStringField(TEXT("getter_param"), GetterParam);
		if (UPCGSubgraphSettings* Subgraph = Cast<UPCGSubgraphSettings>(Settings))
		{
			UPCGGraphInstance* Instance = Subgraph->SubgraphInstance;
			Out->SetStringField(TEXT("subgraph"), Instance && Instance->Graph ? Instance->Graph->GetPathName() : FString());
			Out->SetObjectField(TEXT("overrides"), Instance ? ExportOverrides(Instance) : MakeShared<FJsonObject>());
		}
		Out->SetArrayField(TEXT("pin_defaults"), Settings ? ExportPinDefaults(Settings) : TArray<TSharedPtr<FJsonValue>>());

		TArray<TSharedPtr<FJsonValue>> Inputs;
		for (const TObjectPtr<UPCGPin>& Pin : Node->GetInputPins())
		{
			TArray<TSharedPtr<FJsonValue>> Edges;
			for (const TObjectPtr<UPCGEdge>& Edge : Pin->Edges)
			{
				const UPCGPin* Other = Edge ? Edge->GetOtherPin(Pin.Get()) : nullptr;
				if (Other && Other->Node)
				{
					TArray<TSharedPtr<FJsonValue>> Pair;
					Pair.Add(MakeShared<FJsonValueString>(Other->Node->GetName()));
					Pair.Add(MakeShared<FJsonValueString>(Other->Properties.Label.ToString()));
					Edges.Add(MakeShared<FJsonValueArray>(Pair));
				}
			}
			const TSharedRef<FJsonObject> PinJson = MakeShared<FJsonObject>();
			PinJson->SetStringField(TEXT("label"), Pin->Properties.Label.ToString());
			PinJson->SetArrayField(TEXT("edges"), Edges);
			Inputs.Add(MakeShared<FJsonValueObject>(PinJson));
		}
		Out->SetArrayField(TEXT("inputs"), Inputs);
		TArray<TSharedPtr<FJsonValue>> Outputs;
		for (const TObjectPtr<UPCGPin>& Pin : Node->GetOutputPins())
		{
			Outputs.Add(MakeShared<FJsonValueString>(Pin->Properties.Label.ToString()));
		}
		Out->SetArrayField(TEXT("outputs"), Outputs);
		return Out;
	}
}

FString UPyPCGToolsLibrary::ExportGraphIR(UPCGGraph* Graph)
{
	const TSharedRef<FJsonObject> Root = MakeShared<FJsonObject>();
	if (!Graph)
	{
		Root->SetStringField(TEXT("error"), TEXT("null graph"));
		return Write(Root);
	}
	const TSet<FString> GraphStrip = {TEXT("Nodes"), TEXT("InputNode"), TEXT("OutputNode"), TEXT("UserParameters"),
		TEXT("UserParameterHierarchyRoot"), TEXT("CommentNodes"), TEXT("ExtraEditorNodes"), TEXT("CachedPins"),
		TEXT("LastEditedDocuments"), TEXT("EmbeddedSubgraphs")};
	Root->SetNumberField(TEXT("schema"), 1);
	Root->SetStringField(TEXT("graph"), Graph->GetPathName());
	Root->SetObjectField(TEXT("graph_props"), NonDefault(Graph, GraphStrip));
	Root->SetArrayField(TEXT("params"), ExportParams(Graph));
	Root->SetArrayField(TEXT("comment_boxes"), ExportBoxes(Graph));
	TArray<UPCGNode*> All = {Graph->GetInputNode(), Graph->GetOutputNode()};
	for (UPCGNode* Node : Graph->GetNodes())
	{
		All.Add(Node);
	}
	TArray<TSharedPtr<FJsonValue>> Nodes;
	for (UPCGNode* Node : All)
	{
		if (Node)
		{
			Nodes.Add(MakeShared<FJsonValueObject>(ExportNode(Graph, Node)));
		}
	}
	Root->SetArrayField(TEXT("nodes"), Nodes);
	return Write(Root);
}

FString UPyPCGToolsLibrary::SetPropertiesJson(UObject* Object, const FString& Json)
{
	if (!Object)
	{
		return TEXT("null object");
	}
	FString Error;
	if (IsProtected(Object, Error))
	{
		return Error;
	}
	const TSharedPtr<FJsonObject> Parsed = ParseObject(Json, Error);
	if (!Parsed)
	{
		return Error;
	}
	Object->Modify();
	const TSharedRef<FJsonObject> Regular = MakeShared<FJsonObject>();
	for (const auto& Field : Parsed->Values)
	{
		FProperty* Property = FindFProperty<FProperty>(Object->GetClass(), *Field.Key);
		if (!Property)
		{
			return FString::Printf(TEXT("%s has no property '%s'"), *Object->GetClass()->GetName(), *Field.Key);
		}
		FString Text;
		if (Field.Value->Type == EJson::String && Field.Value->TryGetString(Text) && Text.StartsWith(TextPrefix))
		{
			if (!JsonToProperty(Field.Value, Property, Property->ContainerPtrToValuePtr<void>(Object), Object, Error))
			{
				return Error;
			}
		}
		else
		{
			Regular->SetField(Field.Key, Field.Value);
		}
	}
	FText Fail;
	// With the object as its own container, instanced subobjects are created with the object as Outer.
	if (Regular->Values.Num() > 0 && !FJsonObjectConverter::JsonObjectToUStruct(Regular, Object->GetClass(), Object, 0, 0, false, &Fail))
	{
		return FString::Printf(TEXT("JsonObjectToUStruct failed: %s"), *Fail.ToString());
	}
	RefreshNode(Object);
	return FString();
}

FString UPyPCGToolsLibrary::SetInstanceParameter(UPCGGraphInstance* Instance, FName Name, const FString& ValueJson)
{
	if (!Instance)
	{
		return TEXT("null instance");
	}
	FString Error;
	if (IsProtected(Instance, Error))
	{
		return Error;
	}
	const TSharedPtr<FJsonObject> Wrap = ParseObject(ValueJson, Error);
	if (!Wrap)
	{
		return Error;
	}
	FInstancedPropertyBag& Bag = Instance->ParametersOverrides.Parameters;
	const FPropertyBagPropertyDesc* Desc = Bag.FindPropertyDescByName(Name);
	if (!Desc || !Desc->CachedProperty)
	{
		TArray<FString> Names;
		if (const UPropertyBag* BagStruct = Bag.GetPropertyBagStruct())
		{
			for (const FPropertyBagPropertyDesc& Each : BagStruct->GetPropertyDescs())
			{
				Names.Add(Each.Name.ToString());
			}
		}
		return FString::Printf(TEXT("instance has no parameter %s; parameters: %s"), *Name.ToString(), *FString::Join(Names, TEXT(", ")));
	}
	Instance->Modify();
	void* Data = Desc->CachedProperty->ContainerPtrToValuePtr<void>(Bag.GetMutableValue().GetMemory());
	if (!JsonToProperty(Wrap->TryGetField(TEXT("v")), Desc->CachedProperty, Data, Instance, Error))
	{
		return Error;
	}
	// Mark explicitly: official graphs keep overrides whose value equals the parent default.
	Instance->UpdatePropertyOverride(Desc->CachedProperty, true);
	Instance->OnGraphParametersChanged(EPCGGraphParameterEvent::ValueModifiedLocally, Name);
	return FString();
}

FString UPyPCGToolsLibrary::SetPinDefaultValue(UPCGSettings* Settings, int32 PinIndex, const FString& TypeName, const FString& ValueJson, bool bHasValue, bool bActivated)
{
	UPCGMetadataSettingsBase* Metadata = Cast<UPCGMetadataSettingsBase>(Settings);
	IPCGSettingsDefaultValueProvider* Provider = Cast<IPCGSettingsDefaultValueProvider>(Settings);
	if (!Metadata || !Provider)
	{
		return TEXT("not a metadata node with inline pin defaults");
	}
	FString Error;
	if (IsProtected(Settings, Error))
	{
		return Error;
	}
	if (PinIndex < 0 || PinIndex > 3)
	{
		return FString::Printf(TEXT("pin index %d out of range 0..3"), PinIndex);
	}
	const FName Pin = Metadata->GetInputPinLabel(PinIndex);
	if (!Provider->IsPinDefaultValueEnabled(Pin))
	{
		return FString::Printf(TEXT("pin %d (%s) has no inline default"), PinIndex, *Pin.ToString());
	}
	Settings->Modify();
	Provider->SetPinDefaultValueIsActivated(Pin, true, true);
	if (bHasValue)
	{
		const int64 Type = StaticEnum<EPCGMetadataTypes>()->GetValueByNameString(TypeName);
		if (Type == INDEX_NONE)
		{
			return FString::Printf(TEXT("unknown metadata type %s"), *TypeName);
		}
		if (Provider->GetPinDefaultValueType(Pin) != static_cast<EPCGMetadataTypes>(Type))
		{
			Provider->ConvertPinDefaultValueMetadataType(Pin, static_cast<EPCGMetadataTypes>(Type));
		}
		// Creates the bag property; the exact value is written below from JSON.
		Provider->SetPinDefaultValue(Pin, FString(), true);
		TSet<FName>* Activated = nullptr;
		FInstancedPropertyBag* Bag = DefaultValueBag(Settings, &Activated);
		const FName Prop = *FString::Printf(TEXT("DefaultValue%d"), PinIndex + 1);
		const FPropertyBagPropertyDesc* Desc = Bag ? Bag->FindPropertyDescByName(Prop) : nullptr;
		if (!Desc || !Desc->CachedProperty)
		{
			return FString::Printf(TEXT("%s was not created"), *Prop.ToString());
		}
		const TSharedPtr<FJsonObject> Wrap = ParseObject(ValueJson, Error);
		if (!Wrap)
		{
			return Error;
		}
		void* Data = Desc->CachedProperty->ContainerPtrToValuePtr<void>(Bag->GetMutableValue().GetMemory());
		if (!JsonToProperty(Wrap->TryGetField(TEXT("v")), Desc->CachedProperty, Data, Settings, Error))
		{
			return Error;
		}
	}
	if (!bActivated)
	{
		Provider->SetPinDefaultValueIsActivated(Pin, false, true);
	}
	RefreshNode(Settings);
	return FString();
}

FString UPyPCGToolsLibrary::SetGraphUserParameters(UPCGGraph* Graph, const FString& Json)
{
	if (!Graph)
	{
		return TEXT("null graph");
	}
	FString Error;
	if (IsProtected(Graph, Error))
	{
		return Error;
	}
	const TSharedPtr<FJsonObject> Parsed = ParseObject(Json, Error);
	if (!Parsed)
	{
		return Error;
	}
	const TArray<TSharedPtr<FJsonValue>>* Params = nullptr;
	if (!Parsed->TryGetArrayField(TEXT("params"), Params))
	{
		return TEXT("missing 'params'");
	}
	TArray<FPropertyBagPropertyDesc> Descs;
	for (const TSharedPtr<FJsonValue>& Value : *Params)
	{
		const TSharedPtr<FJsonObject> Param = Value->AsObject();
		const FString Name = Param->GetStringField(TEXT("name"));
		const int64 Type = StaticEnum<EPropertyBagPropertyType>()->GetValueByNameString(Param->GetStringField(TEXT("type")));
		const int64 Container = StaticEnum<EPropertyBagContainerType>()->GetValueByNameString(Param->GetStringField(TEXT("container")));
		if (Type == INDEX_NONE || Container == INDEX_NONE)
		{
			return FString::Printf(TEXT("param %s: unknown type or container"), *Name);
		}
		const FString TypeObjectPath = Param->GetStringField(TEXT("type_object"));
		const UObject* TypeObject = TypeObjectPath.IsEmpty() ? nullptr : LoadObject<UObject>(nullptr, *TypeObjectPath);
		if (!TypeObjectPath.IsEmpty() && !TypeObject)
		{
			return FString::Printf(TEXT("param %s: cannot load %s"), *Name, *TypeObjectPath);
		}
		FPropertyBagPropertyDesc Desc(FName(*Name), static_cast<EPropertyBagContainerType>(Container), static_cast<EPropertyBagPropertyType>(Type), TypeObject);
#if WITH_EDITOR
		const TSharedPtr<FJsonObject>* Meta = nullptr;
		if (Param->TryGetObjectField(TEXT("meta"), Meta))
		{
			for (const auto& Entry : (*Meta)->Values)
			{
				if (Entry.Key != TEXT("Category") && Entry.Key != TEXT("ToolTip"))
				{
					Desc.SetMetaData(FName(*Entry.Key), Entry.Value->AsString());
				}
			}
		}
		const FString Category = Param->GetStringField(TEXT("category"));
		const FString Tooltip = Param->GetStringField(TEXT("tooltip"));
		if (!Category.IsEmpty())
		{
			Desc.SetMetaData(TEXT("Category"), Category);
		}
		if (!Tooltip.IsEmpty())
		{
			Desc.SetMetaData(TEXT("ToolTip"), Tooltip);
		}
#endif
		Descs.Add(MoveTemp(Desc));
	}
	Graph->Modify();
	Graph->UpdateUserParametersStruct([](FInstancedPropertyBag& Bag) { Bag.Reset(); });
	if (Descs.Num() > 0)
	{
		const EPropertyBagAlterationResult Result = Graph->AddUserParameters(Descs);
		if (Result != EPropertyBagAlterationResult::Success)
		{
			return FString::Printf(TEXT("AddUserParameters failed (%d)"), static_cast<int32>(Result));
		}
	}
	FString ValueError;
	Graph->UpdateUserParametersStruct([&](FInstancedPropertyBag& Bag)
	{
		for (const TSharedPtr<FJsonValue>& Value : *Params)
		{
			const TSharedPtr<FJsonObject> Param = Value->AsObject();
			const FPropertyBagPropertyDesc* Desc = Bag.FindPropertyDescByName(FName(*Param->GetStringField(TEXT("name"))));
			if (!Desc || !Desc->CachedProperty)
			{
				ValueError = TEXT("parameter vanished after AddUserParameters");
				return;
			}
			void* Data = Desc->CachedProperty->ContainerPtrToValuePtr<void>(Bag.GetMutableValue().GetMemory());
			if (!JsonToProperty(Param->TryGetField(TEXT("value")), Desc->CachedProperty, Data, Graph, ValueError))
			{
				return;
			}
		}
	});
	if (!ValueError.IsEmpty())
	{
		return ValueError;
	}
	if (UObject* HierarchyRoot = Graph->GetUserParameterHierarchyRoot())
	{
		ClearChildren(HierarchyRoot);
		if (IPCGEditorModule* Editor = IPCGEditorModule::Get())
		{
			Editor->TransferPropertyBagMetadataIntoHierarchy(Graph);
		}
	}
	return FString();
}

FString UPyPCGToolsLibrary::BindUserParameterGetter(UPCGSettings* Getter, FName ParamName)
{
	UPCGUserParameterGetSettings* GetterSettings = Cast<UPCGUserParameterGetSettings>(Getter);
	if (!GetterSettings)
	{
		return TEXT("not a Get Graph Parameter node");
	}
	FString Error;
	if (IsProtected(GetterSettings, Error))
	{
		return Error;
	}
	const UPCGGraph* Graph = GetterSettings->GetTypedOuter<UPCGGraph>();
	const FInstancedPropertyBag* Bag = Graph ? Graph->GetUserParametersStruct() : nullptr;
```

```python
# pypcg_spike.py -- Task 2 spike. Writes ONLY /Game/PyPCG/_Spike/PyPCG_SpikeGraph.
# Args: {"phase": "build" | "reload" | "clear"}
#   build  : make the graph (params, getter, pin default, comment box, named reroute, enum override), save it
#   reload : reload the package from disk and export it again; compare with the export taken at build
#   clear  : delete the spike asset
import gc
import json
import os

import unreal

PATH = "/Game/PyPCG/_Spike/PyPCG_SpikeGraph"
SNAP = os.path.join(unreal.Paths.project_saved_dir(), "Reports", "pypcg_spike_build.json")
L = unreal.PyPCGToolsLibrary


def _pin_labels(node, which):
    return [str(p.get_editor_property("properties").get_editor_property("label"))
            for p in node.get_editor_property(which)]


def _edges_on(node, label):
    for p in node.get_editor_property("input_pins"):
        if str(p.get_editor_property("properties").get_editor_property("label")) == label:
            return len(p.get_editor_property("edges"))
    return -1


def build():
    EAL = unreal.EditorAssetLibrary
    if EAL.does_asset_exist(PATH):
        return {"abort": "spike asset exists; run phase clear first"}
    pkg, name = PATH.rsplit("/", 1)
    g = unreal.AssetToolsHelpers.get_asset_tools().create_asset(name, pkg, unreal.PCGGraph, unreal.PCGGraphFactory())
    if g is None:
        return {"abort": "create_asset returned None"}
    R = {}
    R["params"] = L.set_graph_user_parameters(g, json.dumps({"params": [
        {"name": "Ratio", "type": "Double", "container": "None", "type_object": "", "meta": {},
         "value": 0.9, "category": "Road Parameters", "tooltip": "spike tip"}]}))
    getter, gs = g.add_node_of_type(unreal.load_class(None, "/Script/PCG.PCGUserParameterGetSettings"))
    R["bind"] = L.bind_user_parameter_getter(gs, "Ratio")
    maths, ms = g.add_node_of_type(unreal.load_class(None, "/Script/PCG.PCGMetadataMathsSettings"))
    R["pin_default"] = L.set_pin_default_value(ms, 1, "Double", json.dumps({"v": 2.0}), True, True)
    R["comment"] = L.set_node_comment(maths, "spike comment", True, False)
    maths.set_node_position(0, 0)
    getter.set_node_position(-300, 0)
    R["boxes"] = L.set_graph_comment_boxes(g, json.dumps({"boxes": [
        {"NodePosX": -400, "NodePosY": -100, "NodeWidth": 600, "NodeHeight": 300,
         "NodeComment": "SPIKE BOX", "FontSize": 18}]}))
    # Q3: named reroute declaration -> usage
    decl, ds = g.add_node_of_type(unreal.load_class(None, "/Script/PCG.PCGNamedRerouteDeclarationSettings"))
    use, us = g.add_node_of_type(unreal.load_class(None, "/Script/PCG.PCGNamedRerouteUsageSettings"))
    R["decl_out_pins"] = _pin_labels(decl, "output_pins")
    R["use_in_pins"] = _pin_labels(use, "input_pins")
    R["set_declaration"] = L.set_properties_json(us, json.dumps({"Declaration": ds.get_path_name()}))
    before = _edges_on(use, "In")
    g.add_edge(decl, "InvisiblePin", use, "In")
    R["invisible_edge_created"] = _edges_on(use, "In") == before + 1
    # Q4: user-defined enum override
    trace, ts = g.add_node_of_type(unreal.load_class(None, "/Script/PCG.PCGSubgraphSettings"))
    ts.set_subgraph(unreal.load_asset("/PCGPrimitives/Primitives/Trace/Trace_Bound_Footprint"))
    inst = ts.get_editor_property("subgraph_instance")
    R["enum_set"] = L.set_instance_parameter(inst, "PlanarSurface", json.dumps({"v": "NewEnumerator4"}))
    R["enum_read"] = json.loads(L.export_instance_overrides(inst)).get("PlanarSurface")
    ir = json.loads(L.export_graph_ir(g))
    os.makedirs(os.path.dirname(SNAP), exist_ok=True)
    with open(SNAP, "w", encoding="utf-8") as fh:
        json.dump(ir, fh, indent=1, sort_keys=True)
    R["saved"] = bool(EAL.save_asset(PATH, only_if_is_dirty=False))
    return R


def reload():
    pkg = unreal.find_package(PATH)
    R = {}
    try:
        unreal.EditorLoadingAndSavingUtils.reload_packages([pkg], unreal.ReloadPackagesInteractionMode.ASSUME_POSITIVE)
        R["reloaded"] = True
    except Exception as ex:
        R["reload_error"] = "%s: %s" % (type(ex).__name__, str(ex)[:200])
    g = unreal.EditorAssetLibrary.load_asset(PATH)
    after = json.loads(L.export_graph_ir(g))
    with open(SNAP, encoding="utf-8") as fh:
        before = json.load(fh)
    keys = ("params", "comment_boxes", "nodes", "graph_props")
    R["equal"] = {k: json.dumps(before.get(k), sort_keys=True) == json.dumps(after.get(k), sort_keys=True) for k in keys}
    if not all(R["equal"].values()):
        diff_path = SNAP.replace(".json", "_after.json")
        with open(diff_path, "w", encoding="utf-8") as fh:
            json.dump(after, fh, indent=1, sort_keys=True)
        R["after_written"] = diff_path
    return R


def clear():
    ok = unreal.EditorAssetLibrary.delete_asset(PATH)
    return {"deleted": bool(ok), "exists": unreal.EditorAssetLibrary.does_asset_exist(PATH)}


def main():
    phase = (mcp_args or {}).get("phase", "build")
    return {"build": build, "reload": reload, "clear": clear}[phase]()


mcp_result = json.loads(json.dumps(main(), default=str))
gc.collect()
```

```python
"""Graph IR: plain JSON in the shape UPyPCGToolsLibrary.ExportGraphIR writes. No unreal import."""
import json
import os
import re

SCHEMA = 1
IN_NODE = "DefaultInputNode"
OUT_NODE = "DefaultOutputNode"
IO_NODES = (IN_NODE, OUT_NODE)

_QUOTED_PATH = re.compile(r"'([^']+)'$")


def load(path):
    with open(path, encoding="utf-8") as fh:
        return json.load(fh)


def dump(ir, path):
    os.makedirs(os.path.dirname(os.path.abspath(path)), exist_ok=True)
    with open(path, "w", encoding="utf-8") as fh:
        json.dump(ir, fh, indent=1, ensure_ascii=False, sort_keys=True)
        fh.write("\n")


def alias_of(path):
    """'/PCGPrimitives/Primitives/Get/Get_ActorData.Get_ActorData' -> 'Get_ActorData'."""
    return path.rsplit("/", 1)[-1].split(".", 1)[0]


def object_path(text):
    """"/Script/PCG.Class'/Pkg.Obj:Sub.X'" -> "/Pkg.Obj:Sub.X"; a bare path comes back unchanged."""
    m = _QUOTED_PATH.search(text)
    return m.group(1) if m else text


def node_refs_to_names(value, graph_path):
    """Replace every object path inside `graph_path` by {"node_ref": <node name>}, recursively.

    A named-reroute usage stores its declaration as the declaration's settings object, e.g.
    ".../PCG_3_1_4_Lots.PCG_3_1_4_Lots:NamedRerouteDeclaration_6.PCGNamedRerouteDeclarationSettings_12".
    Two graphs only compare once those paths are reduced to node names."""
    prefix = graph_path + ":"
    if isinstance(value, str):
        p = object_path(value)
        if graph_path and p.startswith(prefix):
            return {"node_ref": p[len(prefix):].split(".", 1)[0]}
        return value
    if isinstance(value, list):
        return [node_refs_to_names(v, graph_path) for v in value]
    if isinstance(value, dict):
        if set(value) == {"node_ref"}:
            return value
        return {k: node_refs_to_names(v, graph_path) for k, v in value.items()}
    return value
```

```python
"""Structural comparison of two graph IRs (spec section 3.5). No unreal import.

Nodes are paired by a bijection found with colour refinement plus individualisation, never by
object name, so a Python-built graph compares equal to the official one when every class,
title, comment, non-default setting, subgraph override, pin default, getter binding and
input edge (in per-pin order) matches.
"""
from . import ir as _ir

NODE_FIELDS = ("class", "title", "title_color", "comment", "bubble_visible", "bubble_pinned",
               "settings", "subgraph", "overrides", "pin_defaults", "getter_param")
_DEFAULTS = {"title": "", "title_color": None, "comment": "", "bubble_visible": False,
             "bubble_pinned": False, "settings": {}, "subgraph": "", "overrides": {},
             "pin_defaults": [], "getter_param": ""}
PARAM_FIELDS = ("name", "type", "container", "type_object", "value", "category", "tooltip", "meta")
IGNORED_META = ("Category", "ToolTip")      # carried by the hierarchy instead (ruling R5)
_WHITE = (1.0, 1.0, 1.0, 1.0)


def canon(v):
    """Hashable, type-aware form: True != 1, but 100000 == 100000.0."""
    if isinstance(v, bool):
        return ("b", v)
    if isinstance(v, (int, float)):
        return ("n", float(v))
    if isinstance(v, str):
        return ("s", v)
    if v is None:
        return ("z",)
    if isinstance(v, (list, tuple)):
        return ("l",) + tuple(canon(x) for x in v)
    if isinstance(v, dict):
        return ("d",) + tuple(sorted((str(k), canon(x)) for k, x in v.items()))
    raise TypeError("not JSON: %r" % (v,))


def refs(value, out=None):
    """Node names referenced by {"node_ref": name} anywhere inside value."""
    out = [] if out is None else out
    if isinstance(value, dict):
        if set(value) == {"node_ref"}:
            out.append(value["node_ref"])
        else:
            for v in value.values():
                refs(v, out)
    elif isinstance(value, list):
        for v in value:
            refs(v, out)
    return out


def _blank_refs(value):
    if isinstance(value, dict):
        if set(value) == {"node_ref"}:
            return {"node_ref": "?"}
        return {k: _blank_refs(v) for k, v in value.items()}
    if isinstance(value, list):
        return [_blank_refs(v) for v in value]
    return value


def _rename_refs(value, mapping):
    if isinstance(value, dict):
        if set(value) == {"node_ref"}:
            return {"node_ref": mapping.get(value["node_ref"], "?" + value["node_ref"])}
        return {k: _rename_refs(v, mapping) for k, v in value.items()}
    if isinstance(value, list):
        return [_rename_refs(v, mapping) for v in value]
    return value


def tooltip_of(param):
    if "tooltip" in param:
        return param["tooltip"] or ""
    for v in (param.get("hier_meta") or {}).get("Values", []):
        if str(v.get("_structType", "")).endswith("PropertyBagPropertyMetadata_Common"):
            return v.get("Tooltip") or ""
    return ""


def _param(p):
    out = {k: p.get(k, "") for k in ("name", "type", "container", "type_object", "category")}
    out["value"] = p.get("value")
    out["tooltip"] = tooltip_of(p)
    out["meta"] = {k: v for k, v in (p.get("meta") or {}).items() if k not in IGNORED_META}
    return out


def _pin_default(d):
    return {"index": d["index"], "activated": bool(d.get("activated")),
            "type": d.get("type"), "value": d.get("value")}


def view(ir, fresh_seeds):
    """Normalised per-node fields: node_refs by name, fresh seeds dropped, defaults filled."""
    graph = ir.get("graph", "")
    nodes = {}
    for n in ir["nodes"]:
        f = {k: n.get(k, _DEFAULTS.get(k)) for k in NODE_FIELDS}
        if f["title_color"] is not None and tuple(float(c) for c in f["title_color"]) == _WHITE:
            f["title_color"] = None
        settings = _ir.node_refs_to_names(dict(f["settings"] or {}), graph)
        seed = fresh_seeds.get(f["class"])
        if seed is not None and settings.get("Seed") == seed:
            settings.pop("Seed")
        f["settings"] = settings
        f["overrides"] = dict(f["overrides"] or {})
        f["pin_defaults"] = sorted((_pin_default(d) for d in f["pin_defaults"] or []), key=lambda d: d["index"])
        f["subgraph"] = f["subgraph"] or ""
        f["getter_param"] = f["getter_param"] or ""
        inputs = [(p["label"], [tuple(e) for e in p["edges"]]) for p in n.get("inputs", []) if p.get("edges")]
        nodes[n["name"]] = {"fields": f, "inputs": inputs, "pos": n.get("pos"),
                            "where": n.get("src") or n.get("title") or n["name"], "step": n.get("step")}
    return nodes


def match(va, vb):
    """Pair node names of view va with view vb: (mapping a->b, unmatched_a, unmatched_b)."""
    sides = {"a": va, "b": vb}
    color = {}
    outs = {}
    for s, v in sides.items():
        for name, n in v.items():
            color[(s, name)] = hash(("io", name)) if name in _ir.IO_NODES else hash(canon(_blank_refs(n["fields"])))
            outs[(s, name)] = []
        for name, n in v.items():
            for label, edges in n["inputs"]:
                for i, (src, pin) in enumerate(edges):
                    if (s, src) in outs:
                        outs[(s, src)].append((pin, name, label, i))

    def refine():
        nonlocal color
        while True:
            new = {}
            for (s, name), c in color.items():
                n = sides[s][name]
                ins = sorted(((label, i, color.get((s, src)), pin)
                              for label, edges in n["inputs"] for i, (src, pin) in enumerate(edges)), key=repr)
                o = sorted(((pin, color[(s, d)], label, i) for pin, d, label, i in outs[(s, name)]), key=repr)
                r = sorted(repr(color.get((s, x))) for x in refs(n["fields"]["settings"]))
                new[(s, name)] = hash((c, tuple(ins), tuple(o), tuple(r)))
            stable = len(set(new.values())) == len(set(color.values()))
            color = new
            if stable:
                return

    refine()
    mapping, taken = {}, set()
    for io_name in _ir.IO_NODES:            # the input/output nodes always pair with each other
        if io_name in va and io_name in vb:
            mapping[io_name] = io_name
            taken.add(io_name)
    counter = 0
    while True:
        groups = {}
        for (s, name), c in color.items():
            if (s == "a" and name in mapping) or (s == "b" and name in taken):
                continue
            groups.setdefault(c, {"a": [], "b": []})[s].append(name)
        progressed = False
        ambiguous = None
        for g in groups.values():
            if len(g["a"]) == 1 and len(g["b"]) == 1:
                mapping[g["a"][0]] = g["b"][0]
                taken.add(g["b"][0])
                progressed = True
            elif g["a"] and g["b"] and (ambiguous is None or len(g["a"]) < len(ambiguous["a"])):
                ambiguous = g
        if progressed:
            continue
        if ambiguous is None:
            break
        counter += 1
        a0, b0 = sorted(ambiguous["a"])[0], sorted(ambiguous["b"])[0]
        color[("a", a0)] = color[("b", b0)] = hash(("individualised", counter))
        refine()
    # Weak pass: nodes that differ in some field still pair when class, subgraph and title agree
    # (then class + subgraph), so a changed value reports as one field diff, not missing + extra.
    for key in (lambda f: (f["class"], f["subgraph"], f["title"]), lambda f: (f["class"], f["subgraph"])):
        ga, gb = {}, {}
        for name in sorted(va):
            if name not in mapping:
                ga.setdefault(key(va[name]["fields"]), []).append(name)
        for name in sorted(vb):
            if name not in taken:
                gb.setdefault(key(vb[name]["fields"]), []).append(name)
        for k, names in ga.items():
            for x, y in zip(names, gb.get(k, [])):
                mapping[x] = y
                taken.add(y)
    return mapping, sorted(set(va) - set(mapping)), sorted(set(vb) - taken)


def _members(box, nodes):
    x, y = box.get("NodePosX", 0), box.get("NodePosY", 0)
    w, h = box.get("NodeWidth", 0), box.get("NodeHeight", 0)
    return {name for name, n in nodes.items()
            if n["pos"] and x <= n["pos"][0] <= x + w and y <= n["pos"][1] <= y + h}


def diff(a, b, fresh_seeds, check_layout=False):
    """Differences of candidate `a` against reference `b`; [] means structurally equal."""
    va, vb = view(a, fresh_seeds), view(b, fresh_seeds)
    out = []

    def add(kind, where, field, av, bv):
        out.append({"kind": kind, "where": where, "field": field, "a": av, "b": bv})

    ga, gb = a.get("graph_props") or {}, b.get("graph_props") or {}
    for k in sorted(set(ga) | set(gb)):
        if canon(ga.get(k)) != canon(gb.get(k)):
            add("graph", "graph", "graph_props." + k, ga.get(k), gb.get(k))
    pa, pb = [_param(p) for p in a.get("params", [])], [_param(p) for p in b.get("params", [])]
    if [p["name"] for p in pa] != [p["name"] for p in pb]:
        add("graph", "graph", "params", [p["name"] for p in pa], [p["name"] for p in pb])
    else:
        for x, y in zip(pa, pb):
            for k in PARAM_FIELDS:
                if canon(x[k]) != canon(y[k]):
                    add("graph", "graph", "params.%s.%s" % (x["name"], k), x[k], y[k])

    mapping, ua, ub = match(va, vb)
    for name in ua:
        add("extra_node", va[name]["where"], "", va[name]["fields"]["class"], None)
    for name in ub:
        add("missing_node", vb[name]["where"], "", None, vb[name]["fields"]["class"])
    for x, y in sorted(mapping.items()):
        fa, fb = va[x]["fields"], vb[y]["fields"]
        for k in NODE_FIELDS:
            if k in ("settings", "overrides"):
                for key in sorted(set(fa[k]) | set(fb[k])):
                    av = _rename_refs(fa[k].get(key), mapping)
                    bv = fb[k].get(key)
                    if canon(av) != canon(bv):
                        add("node", va[x]["where"], "%s.%s" % (k, key), av, bv)
            elif canon(fa[k]) != canon(fb[k]):
                add("node", va[x]["where"], k, fa[k], fb[k])
        ia = {label: [(mapping.get(s, "?" + s), p) for s, p in edges] for label, edges in va[x]["inputs"]}
        ib = dict(vb[y]["inputs"])
        for label in sorted(set(ia) | set(ib)):
            if ia.get(label) != ib.get(label):
                add("edge", va[x]["where"], "inputs." + label, ia.get(label), ib.get(label))
        if check_layout and canon(va[x]["pos"]) != canon(vb[y]["pos"]):
            add("layout", va[x]["where"], "pos", va[x]["pos"], vb[y]["pos"])

    if check_layout:
        ba, bb = a.get("comment_boxes") or [], b.get("comment_boxes") or []
        if len(ba) != len(bb):
            add("layout", "graph", "comment_boxes", len(ba), len(bb))
        for i, (x, y) in enumerate(zip(ba, bb)):
            for k in sorted(set(x) | set(y)):
                if k != "GUID" and canon(x.get(k)) != canon(y.get(k)):
                    add("layout", "graph", "comment_boxes[%d].%s" % (i, k), x.get(k), y.get(k))
            ma = {mapping.get(n, "?" + n) for n in _members(x, va)}
            mb = _members(y, vb)
            if ma != mb:
                add("layout", "graph", "comment_boxes[%d].members" % i, sorted(ma), sorted(mb))
    return out


def undeclared_changes(ir_x, ir_y):
    """Paths that differ between two IRs of the same stage file (same node names) and are not
    covered by a role/knob site recorded in ir_x["sites"]. Used for the town build (spec 3.6)."""
    sites = [s["where"] for s in ir_x.get("sites", [])]
    changes = []
    for na, nb in zip(ir_x["nodes"], ir_y["nodes"]):
        if na["name"] != nb["name"] or na.get("class") != nb.get("class"):
            changes.append("%s.class" % na["name"])
            continue
        for field in ("settings", "overrides"):
            xa, xb = na.get(field) or {}, nb.get(field) or {}
            for k in sorted(set(xa) | set(xb)):
                if canon(xa.get(k)) != canon(xb.get(k)):
                    changes.append("%s.%s.%s" % (na["name"], field, k))
        for field in ("title", "comment", "pin_defaults", "getter_param", "subgraph", "inputs"):
            if canon(na.get(field)) != canon(nb.get(field)):
                changes.append("%s.%s" % (na["name"], field))
    if len(ir_x["nodes"]) != len(ir_y["nodes"]):
        changes.append("nodes.count")
    for p, q in zip(ir_x.get("params", []), ir_y.get("params", [])):
        if canon(p) != canon(q):
            changes.append("params.%s" % p.get("name"))

    def covered(c):
        return any(c == s or c.startswith(s + ".") or c.startswith(s + "[") or s.startswith(c + ".")
                   or s.startswith(c + "[") for s in sites)
    return [c for c in changes if not covered(c)]


def format_diffs(diffs, limit=40):
    lines = []
    for d in diffs[:limit]:
        lines.append("  %-12s %s  %s: candidate %r, reference %r"
                     % (d["kind"], d["where"], d["field"], d["a"], d["b"]))
    if len(diffs) > limit:
        lines.append("  ... %d more" % (len(diffs) - limit))
    return "\n".join(lines)
```

```python
# pypcg_library.py -- write Content/Python/pypcg/library.json: the real input/output pins and
# parameters of every subgraph the 18 stage graphs use, the pins of every native node class,
# and the seed a freshly created node of each class gets (UPCGSettings seeds new nodes from a

EXTRA_CLASSES = ("PCGRerouteSettings", "PCGNamedRerouteDeclarationSettings", "PCGNamedRerouteUsageSettings",
                 "PCGUserParameterGetSettings", "PCGGenericUserParameterGetSettings",
                 "PCGSubgraphSettings", "PCGLoopSettings")


def _labels(node, which):
    return [str(p.get_editor_property("properties").get_editor_property("label"))
            for p in node.get_editor_property(which)]


def run():
    from pypcg import extract, ir as pir, stages
    snaps = [pir.load(os.path.join(_REPO, "Tools/pypcg/official_ir", n + ".json")) for n in stages.names()]
    seen_sub, seen_cls = {}, {}
    for g in snaps:
        for n in g["nodes"]:
            if n["name"] in pir.IO_NODES:
                continue
            ins = [p["label"] for p in n["inputs"]]
            outs = list(n.get("outputs", []))
            if n.get("subgraph"):
                e = seen_sub.setdefault(pir.alias_of(n["subgraph"]), {"path": n["subgraph"], "inputs": set(), "outputs": set()})
            else:
                e = seen_cls.setdefault(n["class"], {"inputs": set(), "outputs": set()})
            e["inputs"].update(ins)
            e["outputs"].update(outs)
    tmp = unreal.new_object(unreal.PCGGraph, unreal.find_package("/Engine/Transient"), "PYPCG_LIBRARY_PROBE")
    lib = {"subgraphs": {}, "classes": {}, "io": {}, "fresh_seeds": {}}
    sub_cls = unreal.load_class(None, "/Script/PCG.PCGSubgraphSettings")
    for alias, e in sorted(seen_sub.items()):
        sg = unreal.EditorAssetLibrary.load_asset(e["path"].split(".")[0])
        if sg is None:
            raise RuntimeError("cannot load subgraph " + e["path"])
        node, st = tmp.add_node_of_type(sub_cls)
        st.set_subgraph(sg)
        params = {p["name"]: p["type"] for p in extract.export(sg)["params"]}
        lib["subgraphs"][alias] = {"path": e["path"],
                                   "inputs": sorted(set(_labels(node, "input_pins")) | e["inputs"]),
                                   "outputs": sorted(set(_labels(node, "output_pins")) | e["outputs"]),
                                   "params": params}
    for cls_name in sorted(set(seen_cls) | set(EXTRA_CLASSES)):
        cls = unreal.load_class(None, "/Script/PCG." + cls_name)
        if cls is None:
            raise RuntimeError("no class " + cls_name)
        node, st = tmp.add_node_of_type(cls)
        e = seen_cls.get(cls_name, {"inputs": set(), "outputs": set()})
        lib["classes"][cls_name] = {"inputs": sorted(set(_labels(node, "input_pins")) | e["inputs"]),
                                    "outputs": sorted(set(_labels(node, "output_pins")) | e["outputs"])}
        lib["fresh_seeds"][cls_name] = int(st.get_editor_property("seed"))
    inp, outp = tmp.get_input_node(), tmp.get_output_node()
    lib["io"] = {"input_node_inputs": _labels(inp, "input_pins"), "input_node_outputs": _labels(inp, "output_pins"),

    path = os.path.join(_PY, "pypcg", "library.json")
```

```python
"""The Python form of one PCG graph (docs/pypcg-guide.md).

A stage file describes nodes and edges with these calls; Graph.to_ir(profile) returns the
IR shape UPyPCGToolsLibrary.ExportGraphIR writes, so the comparator checks a stage file
against the official graph offline. No unreal import.
"""
import json
import os
import sys
from contextlib import contextmanager

from . import ir as _ir

SIZES = ("Small", "Medium", "Large")
_HERE = os.path.dirname(os.path.abspath(__file__))
_LIBRARY = {}


def library():
    """library.json: the real pins and parameters of every subgraph and node class (Task 4)."""
    if not _LIBRARY:
        with open(os.path.join(_HERE, "library.json"), encoding="utf-8") as fh:
            _LIBRARY.update(json.load(fh))
    return _LIBRARY


def sel(text):
    """An attribute/property selector as UE writes it, e.g. sel("$Position.Z")."""
    return "PCGBegin(%s)PCGEnd" % text


class Role:
    """Upstream actors named by role; the profile turns each name into a soft object path."""

    def __init__(self, *names):
        self.names = list(names)


class Knob:
    """A value a profile may replace (the town's park size); the default is the official value."""

    def __init__(self, name, default):
        self.name = name
        self.default = default


def knob(name, default):
    return Knob(name, default)


class NodeRef:
    """A settings value that points at another node of the same graph."""

    def __init__(self, node):
        self.node = node


class P:
    """One graph user parameter."""

    def __init__(self, name, type, value, container="None", type_object="", category="", tooltip="", meta=None):
        self.name = name
        self.ir = {"name": name, "type": type, "value": value, "container": container,
                   "type_object": type_object, "category": category, "tooltip": tooltip,
                   "meta": dict(meta or {})}


class D:
    """An inline default on input pin number `index` (0-based) of a metadata node."""

    def __init__(self, index, type=None, value=None, activated=True):
        self.ir = {"index": index, "type": type, "value": value, "activated": activated}


class Port:
    __slots__ = ("node", "pin")

    def __init__(self, node, pin):
        self.node = node
        self.pin = pin


class Node:
    def __init__(self, graph, rec):
        object.__setattr__(self, "_g", graph)
        object.__setattr__(self, "_rec", rec)

    @property
    def name(self):
        return self._rec["name"]

    def __getitem__(self, pin):
        self._g._check_out(self._rec, pin)
        return Port(self, pin)

    def __getattr__(self, pin):
        if pin.startswith("_"):
            raise AttributeError(pin)
        return self[pin]


class Declaration(Node):
    def use(self, title=None, **kw):
        return self._g._usage(self, title, kw)


class Graph:
    def __init__(self, name, params=(), graph_props=None, description=None,
                 input_settings=None, output_settings=None):
        self.name = name
        self._params = list(params)
        self._props = dict(graph_props or {})
        if description is not None:
            self._props["Description"] = description
        self._nodes = []
        self._step = None
        self.input = Node(self, self._io(_ir.IN_NODE, input_settings))
        self.output = Node(self, self._io(_ir.OUT_NODE, output_settings))

    def _io(self, name, settings):
        rec = {"name": name, "class": "PCGGraphInputOutputSettings", "title": "",
               "settings": dict(settings or {}), "inputs": [], "src": "", "step": None}
        self._nodes.append(rec)
        return rec

    @contextmanager
    def step(self, number, title):
        old = self._step
        self._step = "%d %s" % (number, title)
        try:
            yield
        finally:
            self._step = old

    @staticmethod
    def _caller():
        frame = sys._getframe(1)
        while frame is not None and os.path.dirname(os.path.abspath(frame.f_code.co_filename)) == _HERE:
            frame = frame.f_back
        if frame is None:
            return ""
        return "%s:%d" % (os.path.basename(frame.f_code.co_filename), frame.f_lineno)

    # ---- library checks
    def _subgraph(self, alias):
        subs = library()["subgraphs"]
        if alias not in subs:
            near = sorted(a for a in subs if a.lower()[:6] == alias.lower()[:6])
            raise KeyError("%s: unknown subgraph %r; similar: %s" % (self._caller(), alias, near))
        return subs[alias]

    def _pins(self, rec, which):
        lib = library()
        if rec["name"] == _ir.IN_NODE:
            return lib["io"]["input_node_" + which]
        if rec["name"] == _ir.OUT_NODE:
            return lib["io"]["output_node_" + which]
        if "subgraph" in rec:
            return lib["subgraphs"][_ir.alias_of(rec["subgraph"])][which]
        return lib["classes"][rec["class"]][which]

    def _check_in(self, rec, label):
        allowed = self._pins(rec, "inputs")
        if label not in allowed:
            raise KeyError("%s: %s has no input pin %r; inputs: %s"
                           % (self._caller(), rec["title"] or rec["class"], label, allowed))

    def _check_out(self, rec, pin):
        allowed = self._pins(rec, "outputs")
        if pin not in allowed:
            raise KeyError("%s: %s has no output pin %r; outputs: %s"
                           % (self._caller(), rec["title"] or rec["class"], pin, allowed))

    # ---- nodes
    def _add(self, cls, title, settings, kw, subgraph=None, overrides=None, defaults=None, getter=None,
             node_type=Node):
        comment = kw.pop("comment", None) or ""
        rec = {"name": "n%d" % len(self._nodes), "class": cls, "title": title or "",
               "settings": dict(settings or {}), "comment": comment,
               "bubble_visible": kw.pop("bubble_visible", bool(comment)),
               "bubble_pinned": kw.pop("bubble_pinned", False),
               "inputs": [], "src": self._caller(), "step": self._step}
        color = kw.pop("title_color", None)
        if color is not None:
            rec["title_color"] = list(color)
        if subgraph is not None:
            rec["subgraph"] = subgraph
            rec["overrides"] = dict(overrides or {})
        if defaults:
            rec["pin_defaults"] = [dict(d.ir) for d in defaults]
        if getter is not None:
            rec["getter_param"] = getter
        pins = dict(kw.pop("pins", None) or {})
        pins.update(kw)
        self._nodes.append(rec)
        for label, src in pins.items():
            self._connect(rec, label, src)
        return node_type(self, rec)

    def sub(self, alias, title="", set=None, settings=None, loop=False, **kw):
        entry = self._subgraph(alias)
        for key in (set or {}):
            if key not in entry["params"]:
                raise KeyError("%s: %s has no parameter %r; parameters: %s"
                               % (self._caller(), alias, key, sorted(entry["params"])))
        return self._add("PCGLoopSettings" if loop else "PCGSubgraphSettings", title, settings, kw,
                         subgraph=entry["path"], overrides=set)

    def loop(self, alias, title="", **kw):
        return self.sub(alias, title, loop=True, **kw)

    def node(self, cls, title="", set=None, defaults=None, **kw):
        if cls not in library()["classes"]:
            raise KeyError("%s: unknown node class %r" % (self._caller(), cls))
        return self._add(cls, title, set, kw, defaults=defaults)

    def param(self, name, title="", set=None, **kw):
        if name not in [p.name for p in self._params]:
            raise KeyError("%s: graph %s has no parameter %r" % (self._caller(), self.name, name))
        return self._add("PCGUserParameterGetSettings", title, set, kw, getter=name)

    def param_path(self, path, title="", set=None, **kw):
        settings = {"PropertyPath": path}
        settings.update(set or {})
        return self._add("PCGGenericUserParameterGetSettings", title, settings, kw)

    def actor_by_tag(self, tag, title="", set=None, **kw):
        overrides = {"ActorTag": tag}
        overrides.update(set or {})
        return self.sub("Get_ActorData", title, set=overrides, **kw)

    def ref(self, roles, title="", set=None, **kw):
        roles = [roles] if isinstance(roles, str) else list(roles)
        overrides = {"ActorReferences": Role(*roles)}
        overrides.update(set or {})
        return self.sub("Get_ActorDataByRef", title, set=overrides, **kw)

    def reroute(self, src, title="", set=None, **kw):
        kw["In"] = src
        return self._add("PCGRerouteSettings", title, set, kw)

    def declare(self, title, src=None, set=None, **kw):
        if src is not None:
            kw["In"] = src
        return self._add("PCGNamedRerouteDeclarationSettings", title, set, kw, node_type=Declaration)

    def _usage(self, decl, title, kw):
        settings = {"Declaration": NodeRef(decl)}
        settings.update(kw.pop("set", None) or {})
        kw["In"] = Port(decl, "InvisiblePin")
        return self._add("PCGNamedRerouteUsageSettings", decl._rec["title"] if title is None else title,
                         settings, kw)

    # ---- edges
    def connect(self, src, node, pin):
        self._connect(node._rec, pin, src)

    def out(self, *srcs):
        for src in srcs:
            self._connect(self.output._rec, "Out", src)

    def _connect(self, rec, label, src):
        self._check_in(rec, label)
        sources = src if isinstance(src, (list, tuple)) else [src]
        entry = next((p for p in rec["inputs"] if p["label"] == label), None)
        if entry is None:
            entry = {"label": label, "edges": []}
            rec["inputs"].append(entry)
        for s in sources:
            port = s if isinstance(s, Port) else Port(s, "Out")
            if not isinstance(port.node, Node):
                raise TypeError("%s: %r is not a node or port" % (self._caller(), s))
            self._check_out(port.node._rec, port.pin)
            entry["edges"].append([port.node.name, port.pin])

    # ---- IR
    def to_ir(self, profile=None):
        roles = getattr(profile, "ROLES", {})
        knobs = getattr(profile, "KNOBS", {})
        sites = []

        def resolve(value, where):
            if isinstance(value, Role):
                missing = [r for r in value.names if r not in roles]
                if missing:
                    raise KeyError("%s: profile has no role %s" % (where, missing))
                sites.append({"where": where, "kind": "role", "roles": list(value.names)})
                return [roles[r] for r in value.names]
            if isinstance(value, Knob):
                sites.append({"where": where, "kind": "knob", "knob": value.name})
                return knobs.get(value.name, value.default)
            if isinstance(value, NodeRef):
                return {"node_ref": value.node.name}
            if isinstance(value, dict):
                return {k: resolve(v, "%s.%s" % (where, k)) for k, v in value.items()}
            if isinstance(value, (list, tuple)):
                return [resolve(v, "%s[%d]" % (where, i)) for i, v in enumerate(value)]
            return value

        nodes = []
        for rec in self._nodes:
            out = dict(rec)
            for field in ("settings", "overrides", "pin_defaults"):
                if field in rec:
                    out[field] = resolve(rec[field], "%s.%s" % (rec["name"], field))
            out["inputs"] = [{"label": p["label"], "edges": [list(e) for e in p["edges"]]} for p in rec["inputs"]]
            nodes.append(out)
        return {"schema": _ir.SCHEMA, "graph": self.name,
                "graph_props": resolve(self._props, "graph_props"),
                "params": [resolve(p.ir, "params.%s" % p.name) for p in self._params],
                "comment_boxes": [], "nodes": nodes, "sites": sites}
```

```python
#!/usr/bin/env python
"""Generate a first-draft stage file from an official graph's IR.

The draft is mechanical: one statement per node in dependency order, all in step 0. A curator
then splits it into the Feishu doc's steps (plan Tasks 9-17); test_stages_l1.py keeps it exact.

    python Tools/pypcg/codegen.py --stage 5            # writes s05_*.py unless it exists
    python Tools/pypcg/codegen.py --stage all --force
"""
import argparse
import json
import keyword
import os
import re
import sys

REPO = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
sys.path.insert(0, os.path.join(REPO, "Content", "Python"))

from pypcg import compare, ir as pir, stages  # noqa: E402

_SEL = re.compile(r"^PCGBegin\((.*)\)PCGEnd$", re.S)
RESERVED = {"title", "set", "settings", "loop", "defaults", "src", "roles", "tag", "path", "pins",
            "comment", "bubble_visible", "bubble_pinned", "title_color", "name", "use", "alias", "cls"}
_TAKEN = {"g", "sel", "P", "D", "NodeRef", "Graph", "SIZES", "knob", "build"}


def snake(text):
    s = re.sub(r"[^0-9A-Za-z]+", "_", text or "").strip("_").lower()
    if not s:
        s = "node"
    if s[0].isdigit():
        s = "n_" + s
    if keyword.iskeyword(s) or s in _TAKEN:
        s += "_"
    return s


def unique(base, used):
    name, k = base, 2
    while name in used:
        name = "%s_%d" % (base, k)
        k += 1
    used.add(name)
    return name


def lit(v, names):
    if isinstance(v, str):
        m = _SEL.match(v)
        return "sel(%r)" % m.group(1) if m else repr(v)
    if v is None or isinstance(v, (bool, int, float)):
        return repr(v)
    if isinstance(v, list):
        return "[" + ", ".join(lit(x, names) for x in v) + "]"
    if isinstance(v, dict):
        if set(v) == {"node_ref"}:
            return "NodeRef(%s)" % names[v["node_ref"]]
        return "{" + ", ".join("%r: %s" % (k, lit(x, names)) for k, x in v.items()) + "}"
    raise TypeError(repr(v))


def port(src, pin, names):
    base = "g.input" if src == pir.IN_NODE else names[src]
    if pin == "Out" and src != pir.IN_NODE:
        return base
    if pin.isidentifier() and not keyword.iskeyword(pin) and pin not in ("name", "use"):
        return "%s.%s" % (base, pin)
    return "%s[%r]" % (base, pin)


def ports(edges, names):
    val = [port(s, p, names) for s, p in edges]
    return val[0] if len(val) == 1 else "[" + ", ".join(val) + "]"


def pin_args(inputs, names, skip=()):
    kwargs, pins = [], []
    for label, edges in inputs:
        if label in skip:
            continue
        expr = ports(edges, names)
        if label.isidentifier() and not keyword.iskeyword(label) and label not in RESERVED:
            kwargs.append("%s=%s" % (label, expr))
        else:
            pins.append("%r: %s" % (label, expr))
    if pins:
        kwargs.append("pins={" + ", ".join(pins) + "}")
    return kwargs


def common(f, names):
    out = []
    if f["comment"]:
        out.append("comment=%r" % f["comment"])
        if not f["bubble_visible"]:
            out.append("bubble_visible=False")
    elif f["bubble_visible"]:
        out.append("bubble_visible=True")
    if f["bubble_pinned"]:
        out.append("bubble_pinned=True")
    if f["title_color"] is not None:
        out.append("title_color=%s" % lit(list(f["title_color"]), names))
    return out


def order(view, ir_nodes):
    todo = [n["name"] for n in ir_nodes if n["name"] not in pir.IO_NODES]
    deps = {n: set() for n in todo}
    for n in todo:
        for _, edges in view[n]["inputs"]:
            deps[n].update(s for s, _ in edges if s in deps)
        deps[n].update(r for r in compare.refs(view[n]["fields"]["settings"]) if r in deps)
    done, out = set(), []
    while len(out) < len(todo):
        ready = next((n for n in todo if n not in done and deps[n] <= done), None)
        if ready is None:
            raise ValueError("cycle among %s" % sorted(set(todo) - done))
        out.append(ready)
        done.add(ready)
    return out


def _is_usage(n):
    decl = n["fields"]["settings"].get("Declaration")
    return (isinstance(decl, dict) and set(decl) == {"node_ref"}
            and n["inputs"] == [("In", [(decl["node_ref"], "InvisiblePin")])])


def statement(name, n, names, roles_by_path, view):
    f = n["fields"]
    cls, title = f["class"], f["title"]
    settings, overrides = dict(f["settings"]), dict(f["overrides"])
    head, args, skip, notes = [], [], set(), []
    if settings.get("bEnabled") is False:
        notes.append("# 不生效：节点已禁用")
    if f["subgraph"]:
        alias = pir.alias_of(f["subgraph"])
        wired = {label for label, _ in n["inputs"]}
        for k in sorted(set(overrides) & wired):
            notes.append("# 不生效：set.%s 被同名 pin 的输入顶掉" % k)
        if alias == "Get_ActorData" and "ActorTag" in overrides and cls == "PCGSubgraphSettings":
            method, head = "actor_by_tag", [repr(overrides.pop("ActorTag"))]
        elif alias == "Get_ActorDataByRef" and "ActorReferences" in overrides and cls == "PCGSubgraphSettings":
            roles = [roles_by_path[p] for p in overrides.pop("ActorReferences")]
            method, head = "ref", [repr(roles[0]) if len(roles) == 1 else repr(roles)]
        else:
            method, head = ("loop" if cls == "PCGLoopSettings" else "sub"), [repr(alias)]
        if title:
            head.append(repr(title))
        if overrides:
            args.append("set=%s" % lit(overrides, names))
        if settings:
            args.append("settings=%s" % lit(settings, names))
        call = "g.%s(" % method
    elif cls == "PCGUserParameterGetSettings":
        head = [repr(f["getter_param"])] + ([repr(title)] if title else [])
        if settings:
            args.append("set=%s" % lit(settings, names))
        call = "g.param("
    elif cls == "PCGGenericUserParameterGetSettings" and "PropertyPath" in settings:
        head = [repr(settings.pop("PropertyPath"))] + ([repr(title)] if title else [])
        if settings:
            args.append("set=%s" % lit(settings, names))
        call = "g.param_path("
    elif cls == "PCGNamedRerouteDeclarationSettings" and title:
        head = [repr(title)]
        src = dict(n["inputs"]).get("In")
        if src:
            head.append(ports(src, names))
            skip.add("In")
        if settings:
            args.append("set=%s" % lit(settings, names))
        call = "g.declare("
    elif cls == "PCGNamedRerouteUsageSettings" and _is_usage(n):
        decl = settings.pop("Declaration")["node_ref"]
        skip.add("In")
        if title != view[decl]["fields"]["title"]:
            head = [repr(title)]
        if settings:
            args.append("set=%s" % lit(settings, names))
        call = "%s.use(" % names[decl]
    elif cls == "PCGRerouteSettings" and [label for label, _ in n["inputs"]] == ["In"]:
        head = [ports(dict(n["inputs"])["In"], names)] + ([repr(title)] if title else [])
        skip.add("In")
        if settings:
            args.append("set=%s" % lit(settings, names))
        call = "g.reroute("
    else:
        head = [repr(cls)] + ([repr(title)] if title else [])
        if settings:
            args.append("set=%s" % lit(settings, names))
        if f["pin_defaults"]:
            ds = []
            for d in f["pin_defaults"]:
                parts = [str(d["index"])]
                if d["type"] is not None or d["value"] is not None:
                    parts += [repr(d["type"]), lit(d["value"], names)]
                if not d["activated"]:
                    parts.append("activated=False")
                ds.append("D(%s)" % ", ".join(parts))
            args.append("defaults=[%s]" % ", ".join(ds))
        call = "g.node("
    args += common(f, names) + pin_args(n["inputs"], names, skip)
    lines = ["        " + x for x in notes]
    lines.append("        %s = %s%s)" % (names[name], call, ", ".join(head + args)))
    return lines


def generate(official_ir, roles_by_path, fresh_seeds, stage_title=""):
    view = compare.view(official_ir, fresh_seeds)
    seq = order(view, official_ir["nodes"])
    used, names = set(), {}
    for name in seq:
        f = view[name]["fields"]
        base = f["title"] or (pir.alias_of(f["subgraph"]) if f["subgraph"] else f["class"].replace("PCG", "").replace("Settings", ""))
        names[name] = unique(snake(base), used)
    graph_name = official_ir["graph"].rsplit("/", 1)[-1].split(".")[0]
    n_nodes = len(official_ir["nodes"])
    n_edges = sum(len(p["edges"]) for x in official_ir["nodes"] for p in x["inputs"])
    params = []
    for p in official_ir.get("params", []):
        extra = []
        for key, default in (("container", "None"), ("type_object", ""), ("category", "")):
            if p.get(key, default) != default:
                extra.append("%s=%r" % (key, p[key]))
        tip = compare.tooltip_of(p)
        if tip:
            extra.append("tooltip=%r" % tip)
        meta = {k: v for k, v in (p.get("meta") or {}).items() if k not in compare.IGNORED_META}
        if meta:
            extra.append("meta=%r" % meta)
        params.append("P(%s)" % ", ".join([repr(p["name"]), repr(p["type"]), lit(p["value"], names)] + extra))
    io = {x: view[x]["fields"]["settings"] for x in pir.IO_NODES}
    head = ["    g = Graph(%r," % graph_name,
            "              params=[%s]," % (",\n                      ".join(params)),
            "              graph_props=%s%s)" % (lit(official_ir.get("graph_props") or {}, names),
                                                 "".join(", %s=%s" % (k, lit(io[n], names)) for k, n in
                                                         (("input_settings", pir.IN_NODE), ("output_settings", pir.OUT_NODE)) if io[n]))]
    body = ['    with g.step(0, "未整理"):']
    for name in seq:
        body += statement(name, view[name], names, roles_by_path, view)
    out_edges = dict(view[pir.OUT_NODE]["inputs"]).get("Out", [])
    tail = []
    if out_edges:
        tail = ["    g.out(%s)" % ", ".join(port(s, p, names) for s, p in out_edges)]
    doc = ['"""%s —— %s（CODEGEN DRAFT：尚未按飞书文档分步整理）' % (graph_name, stage_title),
           "",
           "官方 %d 节点 / %d 边。由 Tools/pypcg/codegen.py 生成；整理规则见 docs/pypcg-guide.md。" % (n_nodes, n_edges),
           '"""',
           "from pypcg import D, Graph, NodeRef, P, sel  # noqa: F401",
           "",
           "",
           "def build():"]
    return "\n".join(doc + head + body + tail + ["    return g", ""])


def main(argv):
    ap = argparse.ArgumentParser()
    ap.add_argument("--stage", required=True)

if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```python
"""Editor only: write a stage IR into a PCG graph asset and check it (spec 3.7, L2)."""
import json

import unreal

from . import compare, ir as _ir

L = unreal.PyPCGToolsLibrary
AUTO_DX, AUTO_DY = 420, 160


def _ok(result, what):
    if result:
        raise RuntimeError("%s: %s" % (what, result))


def _v(value):
    return json.dumps({"v": value})


def _labels(node, which):
    return [str(p.get_editor_property("properties").get_editor_property("label"))
            for p in node.get_editor_property(which)]


def _pin(node, which, label):
    for p in node.get_editor_property(which):
        if str(p.get_editor_property("properties").get_editor_property("label")) == label:
            return p
    return None


def asset(path):
    EAL = unreal.EditorAssetLibrary
    if EAL.does_asset_exist(path):
        return EAL.load_asset(path)
    pkg, name = path.rsplit("/", 1)
    g = unreal.AssetToolsHelpers.get_asset_tools().create_asset(name, pkg, unreal.PCGGraph, unreal.PCGGraphFactory())
    if g is None:
        raise RuntimeError("create_asset returned None for %s (traps.md 15)" % path)
    return g


def _clear(g):
    for n in list(g.get_editor_property("nodes")):
        g.remove_node(n)
    for e in list(g.get_all_edges()):
        # PCGEdge's "output" end is the downstream node (traps.md 23).
        g.remove_edge(e.get_input_node(), e.get_input_pin_label(), e.get_output_node(), e.get_output_pin_label())
    if g.get_all_edges():
        raise RuntimeError("could not clear the edges between the input and output nodes")


def _resolve_refs(value, made):
    if isinstance(value, dict):
        if set(value) == {"node_ref"}:
            return made[value["node_ref"]].get_settings().get_path_name()
        return {k: _resolve_refs(v, made) for k, v in value.items()}
    if isinstance(value, list):
        return [_resolve_refs(v, made) for v in value]
    return value


def _layout(g, ir, made, layout_from, fresh_seeds):
    """Positions and comment boxes come from the official graph through the node bijection
    (ruling R2); nodes without an official partner are placed right of their first input."""
    pos = {}
    boxes = []
    if layout_from:
        mapping, official_ir = layout_from
        off_nodes = {n["name"]: n for n in official_ir["nodes"]}
        for name, off in mapping.items():
            if off in off_nodes and off_nodes[off].get("pos"):
                pos[name] = list(off_nodes[off]["pos"])
        inverse = {v: k for k, v in mapping.items()}
        off_view = compare.view(official_ir, fresh_seeds)
        for box in official_ir.get("comment_boxes", []):
            members = compare._members(box, off_view)
            if all(m in inverse for m in members):
                boxes.append(box)
    stacked = {}
    for n in ir["nodes"]:
        if n["name"] in pos:
            continue
        src = next((e[0] for p in n.get("inputs", []) for e in p["edges"] if e[0] in pos), None)
        x, y = (pos[src][0] + AUTO_DX, pos[src][1]) if src else (0, 0)
        k = stacked.get((x, y), 0)
        stacked[(x, y)] = k + 1
        pos[n["name"]] = [x, y + k * AUTO_DY]
    for name, (x, y) in pos.items():
        made[name].set_node_position(int(x), int(y))
    _ok(L.set_graph_comment_boxes(g, json.dumps({"boxes": boxes})), "comment boxes")
    return len(boxes)


def build(ir, path, reference_ir, layout_from=None, fresh_seeds=None, check_layout=False, save=True):
    fresh_seeds = fresh_seeds or {}
    g = asset(path)
    unreal.get_editor_subsystem(unreal.AssetEditorSubsystem).close_all_editors_for_asset(g)
    _clear(g)
    params = []
    for p in ir.get("params", []):
        q = dict(p)
        q["tooltip"] = compare.tooltip_of(p)
        q.pop("hier_meta", None)
        params.append(q)
    _ok(L.set_graph_user_parameters(g, json.dumps({"params": params})), "user parameters")
    if ir.get("graph_props"):
        _ok(L.set_properties_json(g, json.dumps(ir["graph_props"])), "graph_props")

    made = {_ir.IN_NODE: g.get_input_node(), _ir.OUT_NODE: g.get_output_node()}
    for n in ir["nodes"]:
        if n["name"] in made:
            continue
        cls = unreal.load_class(None, "/Script/PCG." + n["class"])
        if cls is None:
            raise RuntimeError("%s: no node class %s" % (n.get("src") or n["name"], n["class"]))
        node, st = g.add_node_of_type(cls)
        if n.get("subgraph"):
            sg = unreal.EditorAssetLibrary.load_asset(n["subgraph"].split(".")[0])
            if sg is None:
                raise RuntimeError("%s: missing subgraph %s" % (n.get("src") or n["name"], n["subgraph"]))
            st.set_subgraph(sg)
        made[n["name"]] = node

    for n in ir["nodes"]:
        where = n.get("src") or n.get("title") or n["name"]
        node = made[n["name"]]
        st = node.get_settings()
        settings = _resolve_refs(n.get("settings") or {}, made)
        if settings:
            _ok(L.set_properties_json(st, json.dumps(settings)), "%s settings" % where)
        if n.get("subgraph"):
            inst = st.get_editor_property("subgraph_instance")
            for k, v in (n.get("overrides") or {}).items():
                _ok(L.set_instance_parameter(inst, k, _v(v)), "%s override %s" % (where, k))
        for d in n.get("pin_defaults") or []:
            has_value = d.get("type") is not None
            _ok(L.set_pin_default_value(st, int(d["index"]), d.get("type") or "", _v(d.get("value")),
                                        has_value, bool(d.get("activated"))), "%s pin default %s" % (where, d["index"]))
        if n.get("getter_param"):
            _ok(L.bind_user_parameter_getter(st, n["getter_param"]), "%s getter" % where)
        if n.get("title"):
            node.set_editor_property("node_title", n["title"])
        if n.get("title_color"):
            node.set_editor_property("node_title_color", unreal.LinearColor(*n["title_color"]))
        if n.get("comment") or n.get("bubble_visible") or n.get("bubble_pinned"):
            _ok(L.set_node_comment(node, n.get("comment") or "", bool(n.get("bubble_visible")),
                                   bool(n.get("bubble_pinned"))), "%s comment" % where)

    for n in ir["nodes"]:
        dst = made[n["name"]]
        for p in n.get("inputs", []):
            for src_name, src_pin in p["edges"]:
                pin = _pin(dst, "input_pins", p["label"])
                before = len(pin.get_editor_property("edges")) if pin else -1
                g.add_edge(made[src_name], src_pin, dst, p["label"])
                pin = _pin(dst, "input_pins", p["label"])
                if pin is None or len(pin.get_editor_property("edges")) != before + 1:
                    raise RuntimeError("edge %s.%s -> %s.%s not created (traps.md 14); source outputs %s, target inputs %s"
                                       % (src_name, src_pin, n.get("src") or n["name"], p["label"],
                                          _labels(made[src_name], "output_pins"), _labels(dst, "input_pins")))

    kept_boxes = _layout(g, ir, made, layout_from, fresh_seeds)
    built = json.loads(L.export_graph_ir(g))
    diffs = compare.diff(built, reference_ir, fresh_seeds, check_layout=check_layout)
    if not diffs and save:
        if not unreal.EditorAssetLibrary.save_asset(path, only_if_is_dirty=False):
            raise RuntimeError("save_asset failed for " + path)
    for d in diffs:
        d.setdefault("asset", path)
    if layout_from and kept_boxes != len(layout_from[1].get("comment_boxes", [])):
        diffs.append({"kind": "layout", "where": "graph", "field": "comment_boxes.kept",
                      "a": kept_boxes, "b": len(layout_from[1].get("comment_boxes", []))})
    return diffs
```

```python
"""Editor only: what a PCGVolume produced -- per-mesh instance counts, component classes,
output tags, output and component bounds. Used by L3 (Task 8) and the town run (Tasks 20-21)."""
import json

import unreal

DEBUG_CUBE = "/PCG/DebugObjects/"


def volumes():
    eas = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)
    return [a for a in eas.get_all_level_actors() if a.get_class().get_name() == "PCGVolume"]


def actor_by_label(label):
    eas = unreal.get_editor_subsystem(unreal.EditorActorSubsystem)
    for a in eas.get_all_level_actors():
        try:
            if str(a.get_actor_label()) == label:
                return a
        except Exception:
            continue
    return None


volume_by_label = actor_by_label


def bounds_union(boxes):
    boxes = [b for b in boxes if b]
    if not boxes:
        return None
    return [[min(b[0][i] for b in boxes) for i in range(3)], [max(b[1][i] for b in boxes) for i in range(3)]]


def _box(origin, extent):
    return [[origin.x - extent.x, origin.y - extent.y, origin.z - extent.z],
            [origin.x + extent.x, origin.y + extent.y, origin.z + extent.z]]


def record(volume):
    pc = volume.get_component_by_class(unreal.PCGComponent)
    meshes, components, cboxes = {}, {}, []
    for c in volume.get_components_by_class(unreal.PrimitiveComponent):
        cls = c.get_class().get_name()
        if cls == "BrushComponent":
            continue
        components[cls] = components.get(cls, 0) + 1
        n = 0
        try:
            n = int(c.get_instance_count())
        except Exception:
            pass
        mesh = ""
        try:
            sm = c.get_editor_property("static_mesh")
            mesh = sm.get_path_name() if sm else ""
        except Exception:
            pass
        if mesh.startswith(DEBUG_CUBE):
            continue
        if n:
            meshes[mesh] = meshes.get(mesh, 0) + n
        origin, extent, _ = unreal.SystemLibrary.get_component_bounds(c)
        cboxes.append(_box(origin, extent))
    tags, oboxes = set(), []
    coll = pc.get_generated_graph_output()
    for td in coll.get_editor_property("tagged_data"):
        tags.update(str(t) for t in td.get_editor_property("tags"))
        data = td.get_editor_property("data").get_editor_property("data")   # traps.md 46
        try:
            b = data.get_bounds()
            oboxes.append([[b.min.x, b.min.y, b.min.z], [b.max.x, b.max.y, b.max.z]])
        except Exception:
            pass
    return {"generated": bool(pc.get_editor_property("generated")),
            "instances": sum(meshes.values()), "meshes": meshes, "components": components,
            "tags": sorted(tags), "output_bounds": bounds_union(oboxes),
            "component_bounds": bounds_union(cboxes)}


def overrides(pc):
    inst = pc.get_editor_property("graph_instance")
    return json.loads(unreal.PyPCGToolsLibrary.export_instance_overrides(inst)) if inst else {}


def apply_overrides(pc, values):
    inst = pc.get_editor_property("graph_instance")
    for k, v in values.items():
        err = unreal.PyPCGToolsLibrary.set_instance_parameter(inst, k, json.dumps({"v": v}))
        if err:
            raise RuntimeError("override %s: %s" % (k, err))
```

```python
# pypcg_behaviour.py -- L3 (spec 3.6): generate the 18 stages in the demo level with the

# Never saves anything. Phases (one per call):

def _load(path, default):
    if os.path.exists(path):
        with open(path, encoding="utf-8") as fh:
            return json.load(fh)
    return default


def _save(path, data):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w", encoding="utf-8") as fh:
        json.dump(data, fh, indent=1, ensure_ascii=False, sort_keys=True)


def _trace_z(x, y):
    """Z of the first blocking hit straight down at (x, y), None for no hit, or a dict
    describing why the API answer could not be read (the probe's purpose is to find out)."""
    world = unreal.get_editor_subsystem(unreal.UnrealEditorSubsystem).get_editor_world()
    try:
        res = unreal.SystemLibrary.line_trace_single(world, unreal.Vector(x, y, 500000.0), unreal.Vector(x, y, -500000.0),
                                                     unreal.TraceTypeQuery.TRACE_TYPE_QUERY1, True, [],
                                                     unreal.DrawDebugTrace.NONE, True)
    except Exception as ex:
        return {"error": "%s: %s" % (type(ex).__name__, str(ex)[:200])}
    hit = res[-1] if isinstance(res, tuple) else res
    if hit is None:
        return None
    try:
        parts = unreal.GameplayStatics.break_hit_result(hit)
        # (blocking_hit, initial_overlap, time, distance, location, impact_point, ...)
        return float(parts[5].z) if parts[0] else None
    except Exception as ex:
        return {"raw": str(hit)[:300], "error": str(ex)[:120]}


def phase_roles():
    from pypcg import census
    from pypcg.profiles import official
    roles = {}
    for role, path in official.ROLES.items():
        obj = unreal.find_object(None, path)
        row = {"path": path, "found": obj is not None}
        if obj is not None:
            row["label"] = str(obj.get_actor_label())
            row["class"] = obj.get_class().get_name()
            pc = obj.get_component_by_class(unreal.PCGComponent)
            g = pc.get_graph() if pc else None
            row["graph"] = g.get_name() if g else None
            row["splines"] = len(obj.get_components_by_class(unreal.SplineComponent))
            row["location"] = [round(v, 1) for v in obj.get_actor_location().to_tuple()]
        roles[role] = row
    probes = {}
    for label in ("PCG_2_1_MainTower_Footprint", "PCG_2_2_CentralPark_Footprint", "PCG_4_1_MainTower_Visuals"):
        v = census.volume_by_label(label)
        if v is None:
            probes[label] = "missing"
            continue
        pc = v.get_component_by_class(unreal.PCGComponent)
        g = pc.get_graph()
        probes[label] = {"component_overrides": census.overrides(pc),

def phase_cleanup():
    from pypcg import census
    n = 0
    for v in census.volumes():
        v.get_component_by_class(unreal.PCGComponent).cleanup_local(True)
        n += 1
    return {"cleaned": n}


def phase_swap(variant):
    from pypcg import census, stages
    saved = _load(OVERRIDES, None)
    out = {}
    for s in stages.STAGES:
        v = census.volume_by_label(s[1])
        if v is None:
            out[s[1]] = "missing volume"
            continue
        pc = v.get_component_by_class(unreal.PCGComponent)
        if saved is None or s[1] not in saved:
            saved = saved or {}
            saved[s[1]] = census.overrides(pc)
        path = stages.official_path(s[0]) if variant == "official" else "/Game/PyPCG/Official/" + s[1]
        pc.set_graph(unreal.EditorAssetLibrary.load_asset(path))
        census.apply_overrides(pc, saved[s[1]])          # traps.md 44
        out[s[1]] = {"graph": pc.get_graph().get_path_name(), "overrides_back": census.overrides(pc) == saved[s[1]]}
    _save(OVERRIDES, saved)
    return out


def phase_gen(stage):
    from pypcg import census, stages
    v = census.volume_by_label(stages.name(stage))
    pc = v.get_component_by_class(unreal.PCGComponent)
    pc.activate(True)
    pc.generate_local(True)
    return {"stage": stage, "graph": pc.get_graph().get_path_name(), "activated": bool(pc.get_editor_property("activated"))}


def phase_read(stage, variant):
    from pypcg import census, stages
    rec = census.record(census.volume_by_label(stages.name(stage)))
    data = _load(REPORT, {})
    data.setdefault(variant, {})[str(stage)] = rec
    _save(REPORT, data)
    return {"stage": stage, "variant": variant, "generated": rec["generated"], "instances": rec["instances"],
            "meshes": len(rec["meshes"]), "tags": rec["tags"][:12]}


def phase_compare():
    data = _load(REPORT, {})
    rows, ok = [], True
    for s in range(1, 19):
        a = data.get("official", {}).get(str(s))
        b = data.get("pypcg", {}).get(str(s))
        same = a is not None and b is not None and a["meshes"] == b["meshes"] and a["tags"] == b["tags"]
        ok = ok and same
        diff = {}
        if a and b and not same:
            for m in sorted(set(a["meshes"]) | set(b["meshes"])):
                if a["meshes"].get(m) != b["meshes"].get(m):
                    diff[m] = [a["meshes"].get(m), b["meshes"].get(m)]
        rows.append({"stage": s, "official": a and a["instances"], "pypcg": b and b["instances"],
                     "same": same, "mesh_diffs": dict(list(diff.items())[:10])})
    return {"all_same": ok, "rows": rows}


def run(args):
    les = unreal.get_editor_subsystem(unreal.LevelEditorSubsystem)
    if LEVEL not in str(les.get_current_level()):
        return {"abort": "open %s first (relaunch the editor into it)" % LEVEL}
    phase = args.get("phase")
    if phase == "roles":
        return phase_roles()
    if phase == "cleanup":
        return phase_cleanup()
    if phase == "swap":
        return phase_swap(args["variant"])
    if phase == "gen":
        return phase_gen(int(args["stage"]))
    if phase == "read":
        return phase_read(int(args["stage"]), args["variant"])
    if phase == "compare":
        return phase_compare()
    return {"abort": "unknown phase %r" % phase}


try:
    mcp_result = json.loads(json.dumps(run(mcp_args or {}), default=str))
except Exception as _exc:
    mcp_result = {"error": "%s: %s" % (type(_exc).__name__, str(_exc)[:600])}
gc.collect()
```

```python
def _seg_distance(p, a, b):
    (px, py), (ax, ay), (bx, by) = p[:2], a[:2], b[:2]
    dx, dy = bx - ax, by - ay
    t = max(0.0, min(1.0, ((px - ax) * dx + (py - ay) * dy) / float(dx * dx + dy * dy)))
    return math.hypot(px - ax - t * dx, py - ay - t * dy)


def edge_distance(p, polygon):
    return min(_seg_distance(p, polygon[i], polygon[(i + 1) % len(polygon)]) for i in range(len(polygon)))


def polyline_distance(p, polyline):
    return min(_seg_distance(p, polyline[i], polyline[i + 1]) for i in range(len(polyline) - 1))


def inside(p, polygon):
    x, y = p[:2]
    hit = False
    for i in range(len(polygon)):
        (x1, y1), (x2, y2) = polygon[i][:2], polygon[(i + 1) % len(polygon)][:2]
        if (y1 > y) != (y2 > y) and x < x1 + (y - y1) * (x2 - x1) / float(y2 - y1):
            hit = not hit
    return hit


def _cross(a, b, c, d):
    def orient(p, q, r):
        return (q[0] - p[0]) * (r[1] - p[1]) - (q[1] - p[1]) * (r[0] - p[0])
    return (orient(a, b, c) > 0) != (orient(a, b, d) > 0) and (orient(c, d, a) > 0) != (orient(c, d, b) > 0)


def crossings(polyline, shape, closed=True):
    """How many times the open polyline crosses the edges of shape (closed polygon by default)."""
    edges = [(shape[i], shape[(i + 1) % len(shape)]) for i in range(len(shape) if closed else len(shape) - 1)]
    return sum(1 for i in range(len(polyline) - 1) for c, d in edges if _cross(polyline[i], polyline[i + 1], c, d))
```

```python
#!/usr/bin/env python
"""Town census + screenshots -> the manifest Tools/build_pcg_stage_report.py renders.

    python Tools/pypcg/town_manifest.py --out Saved/Reports/pypcg_town_manifest.json
    python Tools/build_pcg_stage_report.py --manifest Saved/Reports/pypcg_town_manifest.json --out docs/pypcg-town-report.html
"""
import argparse
import json
import os
import sys

REPO = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
DATA_ONLY = (1, 4, 5, 6, 9)


def build(census, shots_dir):
    stages = []
    for r in census["stages"]:
        path = os.path.join(shots_dir, r["shot"]) if r.get("shot") else ""
        shot = {"kind": "geometry", "path": path}
        if not path or not os.path.exists(path):
            shot["img_missing"] = "未捕获"
        status = "ok" if r["instances"] else ("empty" if r["stage"] in DATA_ONLY else "missing")
        if r.get("status") == "unmeasured":
            status = "empty"
        notes = "; ".join(r.get("notes") or [])
        if r["stage"] in DATA_ONLY and not r["instances"]:
            notes = (notes + "; " if notes else "") + "数据阶段：产出数据，几何与前一阶段相同。"
        stages.append({"n": r["stage"], "graph": r["graph"], "label": r.get("title", ""), "shots": [shot],
                       "metrics": {"instances": r["instances"], "debug_instances": 0, "status": status},
                       "notes": notes})
    return {"title": "PyPCG 小城镇 · 18 步", "level": census["_level"],
            "subtitle": "用 Python 化的 18 张 City Sample PCG 图，按飞书文档的 18 步顺序在 1 km 小镇里逐步生成；每步一张累计几何截图。",
            "footer": "生成的 Actor 中超过 GitHub 100 MB 单文件上限的未入库（见 .gitignore）；pypcg_town.py 可按顺序重新生成。",
            "stages": stages}


def main(argv):
    ap = argparse.ArgumentParser()
    ap.add_argument("--census", default=os.path.join(REPO, "Tools", "data", "pypcg_town_census.json"))
    ap.add_argument("--shots", default=os.path.join(REPO, "Saved", "Screenshots", "WindowsEditor"))
    ap.add_argument("--out", required=True)
    a = ap.parse_args(argv)
    with open(a.census, encoding="utf-8") as fh:
        manifest = build(json.load(fh), a.shots)
    with open(a.out, "w", encoding="utf-8") as fh:
        json.dump(manifest, fh, indent=1, ensure_ascii=False)
    print("stages", len(manifest["stages"]), "missing shots", sum(1 for s in manifest["stages"] if s["shots"][0].get("img_missing")))
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```
