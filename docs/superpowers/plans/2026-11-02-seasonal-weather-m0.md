# SeasonalWeather M0（骨架）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The skeleton every later milestone builds on.
- The `SeasonalWeather` plugin: weather fields and the manual override, the calendar, the sun / moon / stars, a two-StateTree
  orchestrator, the sky rig, a debug panel and `weather.*` console commands.
- The numpy reference model with golden files.
- The `weather.py` driver and the lab level `/Game/Weather/L_WeatherLab`.
- Acceptance: switching weather type and season by hand visibly changes light, sky, fog and grading.

**Architecture:**
- Three plugin modules:
  - `SeasonalWeatherShaders` (PostConfigInit, global compute shaders only);
  - `SeasonalWeather` (runtime: subsystem, calendar, astronomy, sky, fields, orchestrator);
  - `SeasonalWeatherEditor` (StateTree builders, debug panel).
- Every formula has a Python twin in `Tools/weather/weather_ref`. Python writes golden JSON; C++ automation tests compare
  against it.
- Editor-side assets (MPC, star material, look data assets, the two StateTrees) are generated by `weather.py assets`, never
  hand-edited.

**Tech Stack:** UE 5.8 source build (RDG, StateTree, Slate, Python editor scripting), pytest + numpy + Pillow on system Python 3.14,
the MCP bridge (`run_unreal_script`).

**Spec:** `docs/superpowers/specs/2026-11-02-seasonal-weather-design.md` (commit `e8b039a`, branch `seasonal-weather`); M0 scope is §9.1.
Background and spike results: `docs/acs-shadows-weather-breakdown.md` §6.

**Rulings (planner = executor):**
- **R1: how much code the plan contains.**
  - The plan pins every interface (exact declarations), every test (full code), every formula and every command with its
    expected output.
  - Plain implementation is written test-first directly in the files. This is the project's precedent (see the PyInterior
    plans), since writing it twice would double the work without a handoff to justify it.
  - Engine-API code that is easy to get wrong is given in full: RDG passes, GPU readback, StateTree building and running, and
    the subsystem's sky application.
- **R2: no commit steps.** The user's standing rule is "commit only when asked".
- **P1: fields are allocated lazily.** `params.fields` declares all 12 fields of spec §1.3, and the registry creates a
  render target on first use. The GPU test allocates and checks every one; at run time only the fields someone uses exist.
  - Cost if wrong: none; allocation is already behind `GetOrCreateField`.
- **P2: the moon phase counts game days** (29.53 game days per cycle), while the sun follows the compressed calendar date.
  The moon's elongation from the sun still comes from that phase, so its rise/set geometry is right. The spec's "29.5 天一个周期"
  reads as game days.
  - Cost if wrong: one parameter's unit.
- **P3: the M0 override is all-or-nothing.** M0 has no Atmos, so the override is the only weather source and fills
  `ground_a`, `ground_b`, `coarse_wind` and `atmos_volume` uniformly. Per-field override (spec §1.5) arrives with Atmos in M3.
- **P4: cloud cover in M0 comes from the weather type's look.** Sun dimming and stars use it. The override's cloud cover
  goes only into `ground_b`, because the M0 sky has no cloud field to read yet.
- **P5: the star map is generated outside the editor.** `Tools/weather/gen_starmap.py` (system Python: numpy + Pillow; the
  editor's Python has neither) writes `Saved/Weather/T_WeatherStars.png`. `weather.py assets` imports it, and the imported
  texture is the committed artifact.
- **P6: `weather.py assets` is idempotent.**
  - It creates what is missing and updates values in place.
  - It never recreates the MPC. A material's collection-parameter node stores the parameter's GUID, so new GUIDs would
    break the star material.
- **P7: build and editor sequencing.**
  - Phase A (Tasks 1–6): pure Python; no editor.
  - Phase B (Tasks 7–15): C++, built and tested with **both editors closed**. A new plugin module cannot hot-reload, and
    PCG_Codex's Live Coding blocks builds (memory `two-editors-running`).
  - Phase C (Tasks 16–19): the user reopens the PCG_Claude editor and work goes through the bridge.

## Review Focus

1. **A world with no `AWeatherDomain`** (L_PyWorld opened today, any other level): the subsystem stays inert and creates no
   render targets. → test in Task 14 (`SeasonalWeather.Subsystem.NoDomain`).
2. **Plugin assets not generated yet** (Phase B, or a fresh clone before `weather.py assets`): neutral look, orchestration
   falls back to "active = requested", no errors. → test in Task 14 (`SeasonalWeather.Subsystem.ApplySky` runs without the assets).
3. **Advancing far** (hundreds of game days, many years): season / year / day-of-year stay consistent, no NaN. → golden cases at

4. **Out-of-range control input** (hour 24 or −3, day 99, negative advance before day 0): clamped, never negative time. → tests in

5. **Switching weather type in the middle of a blend**: the new blend starts from what is on screen, with no jump. → test in

### Task 2: Calendar reference (spec §6.1)

**Files:**
- Create: `Tools/weather/weather_ref/calendar.py`
- Test: `Tools/weather/tests/test_weather_calendar.py`

**Interfaces:**
- Produces:
  - `DAY_S = 86400.0`
  - `CalendarState` (namedtuple), fields in this order: `game_seconds day_index hour season next_season day_in_season
    season_fraction in_transition transition_progress weights year day_of_year`. `weights` is a 4-tuple in `SEASONS` order.
  - `evaluate(game_seconds, cal) -> CalendarState`
  - `seconds_for(cal, current_seconds, season, day_in_season, hour) -> float`
  - `with_hour(current_seconds, hour) -> float`
  - `advance(current_seconds, delta_seconds) -> float`

**Rules (the C++ twin in Task 9 copies them operation for operation):**
- Inputs: `L = season_length_days`, `T = transition_days`, `start = SEASONS.index(start_season)`.
- Day and hour:
  - `total = gs / DAY_S`
  - `day_index = floor(total)`
  - `hour = (total - day_index) * 24`
- Season:
  - `ord = day_index // L`, `seq = start + ord`
  - `season = seq % 4`, `next = (season + 1) % 4`
  - `day_in_season = day_index - ord*L`
  - `pos = day_in_season + hour/24`, `fraction = pos / L`
- Transition:
  - `in_transition = T > 0 and pos >= L - T`
  - `progress = min(1, (pos - (L - T)) / T)` when in transition, else 0
  - `weights[season] = 1 - progress`; `weights[next] += progress`
- Day of year and year:
  - `d0, d1 = season_start_doy[season], season_start_doy[next]`; if `d1 <= d0`, add 365 to `d1`.
  - `doy = d0 + fraction*(d1 - d0)`
  - `year = base_year + seq // 4`; if `doy >= 366`, subtract 365 from `doy` and add 1 to `year`.
- `seconds_for` (Review Focus 4):
  - `current < 0` counts as 0.
  - `cycle = (floor(current/DAY_S) // L) // 4`
  - `ord = cycle*4 + (SEASONS.index(season) - start) % 4`
  - `day` is clamped to `0..L-1`, `hour` to `0..23.999999`.
  - Returns `(ord*L + day)*DAY_S + hour*3600`.
- `with_hour(cur, h) = floor(cur/DAY_S)*DAY_S + clamp(h, 0, 23.999999)*3600`
- `advance(cur, d) = max(0, cur + d)`

```python
from weather_ref import calendar as C
from weather_ref import params as P

CAL = P.load()["calendar"]


def at(day, hour=0.0):
    return day * C.DAY_S + hour * 3600.0


def test_day_zero_is_the_start_season():
    s = C.evaluate(at(0, 12.0), CAL)
    assert (s.season, s.next_season, s.day_in_season, s.in_transition, s.year) == ("Spring", "Summer", 0, False, 2026)
    assert s.hour == 12.0 and s.weights == (1.0, 0.0, 0.0, 0.0)
    assert abs(s.day_of_year - (79 + (0.5 / 7) * (172 - 79))) < 1e-9
```

### Task 3: Astronomy reference (NOAA sun, moon)

**Files:**
- Create: `Tools/weather/weather_ref/astronomy.py`
- Test: `Tools/weather/tests/test_weather_astronomy.py`

**Interfaces:**
- Produces:
  - Helpers and constants:
    - `DEG = math.pi / 180.0`, `RAD = 180.0 / math.pi`. Use these, not `math.radians`, so the C++ constants match bit for bit.
    - `wrap(x, m) = x - m*floor(x/m)`
  - Dates:
    - `julian_day(year, month, day) -> float` (00:00 UTC, Meeus ch. 7)
    - `date_jd(year, doy, tz) = julian_day(year, 1, 1) + (doy - 1) + 0.5 - tz/24`: local noon of a possibly fractional day.
      The compressed calendar moves the date continuously, and the time of day enters only through the hour angle.
  - Sun:
    - `Sun` (namedtuple): `elevation_deg azimuth_deg declination_deg eot_min right_ascension_deg hour_angle_deg
      ecliptic_longitude_deg obliquity_deg`
    - `sun(year, doy, local_hour, lat, lon, tz) -> Sun`
    - `sunrise_sunset(year, doy, lat, lon, tz, zenith=90.833) -> (sunrise_h, sunset_h, day_length_h)`
  - Moon:
    - `Moon` (namedtuple): `phase illumination elevation_deg azimuth_deg declination_deg`
    - `moon(game_days, sun, lat, synodic_days, offset_days) -> Moon`
  - Light direction:
    - `direction(el, az, north_yaw) -> (x, y, z)` = `(cos el·cos(az+n), cos el·sin(az+n), sin el)`
    - `light_rotation(el, az, north_yaw) -> (pitch, yaw, roll)` = `(-el, wrap(az + n + 180, 360), 0.0)`

**Formulas.** All in degrees; trigonometry converts with `DEG`/`RAD`. `jd = date_jd(...)`, `t = (jd - 2451545)/36525`.

- Orbital elements (NOAA spreadsheet):
  - `l0 = wrap(280.46646 + t*(36000.76983 + t*0.0003032), 360)`
  - `m = 357.52911 + t*(35999.05029 - 0.0001537*t)`
  - `e = 0.016708634 - t*(0.000042037 + 0.0000001267*t)`
  - `c = sin(m)*(1.914602 - t*(0.004817 + 0.000014*t)) + sin(2m)*(0.019993 - 0.000101*t) + sin(3m)*0.000289`
  - `om = 125.04 - 1934.136*t`
  - `lam = l0 + c - 0.00569 - 0.00478*sin(om)`
  - `eps = 23 + (26 + (21.448 - t*(46.815 + t*(0.00059 - t*0.001813)))/60)/60 + 0.00256*cos(om)`
- Declination and equation of time:
  - `decl = asin(sin(eps)*sin(lam))`
  - `y = tan(eps/2)²`
  - `eot = 4*RAD*(y*sin(2·l0) - 2e·sin(m) + 4e·y·sin(m)·cos(2·l0) - 0.5y²·sin(4·l0) - 1.25e²·sin(2m))` (minutes)
- Hour angle and right ascension:
  - `tst = wrap(local_hour*60 + eot + 4*lon - 60*tz, 1440)`
  - `ha = tst/4 - 180`
  - `ra = wrap(atan2(cos(eps)*sin(lam), cos(lam)), 360)`
- Altitude and azimuth (both bodies):
  - `el = asin(clamp(sin(lat)sin(decl) + cos(lat)cos(decl)cos(ha), -1, 1))`
  - `az = wrap(atan2(sin(ha), cos(ha)sin(lat) - tan(decl)cos(lat)) + 180, 360)` (from north, clockwise)
- Sunrise and sunset:
  - `cos_h = cos(zenith)/(cos(lat)cos(decl)) - tan(lat)tan(decl)`, clamped to [-1, 1]; `h = acos(cos_h)`
  - `noon = (720 - 4*lon - eot + 60*tz)/60`
  - sunrise / sunset `= noon ∓ 4h/60`; day length `= 8h/60`
  - The clamp gives polar day 24 h and polar night 0 h.
- Moon:
  - `phase = wrap((game_days + offset)/synodic, 1)`
  - `illumination = (1 - cos(2π·phase))/2`
  - `lam_m = sun.ecliptic_longitude_deg + 360*phase` (ecliptic latitude 0)
  - `decl_m = asin(sin(eps)sin(lam_m))`, `ra_m = wrap(atan2(cos(eps)sin(lam_m), cos(lam_m)), 360)`
  - `ha_m = wrap(sun.hour_angle_deg + sun.right_ascension_deg - ra_m + 180, 360) - 180`
  - Altitude and azimuth with the formula above, using `eps = sun.obliquity_deg`.

```cpp
void WeatherGpu::AddFillPass(FRDGBuilder& GraphBuilder, FRDGTextureRef Texture, const FVector4f& Value)
{
	RDG_EVENT_SCOPE_STAT(GraphBuilder, WeatherFieldsFill, "Weather.Fields.Fill");
	const FRDGTextureDesc& Desc = Texture->Desc;
	FGlobalShaderMap* ShaderMap = GetGlobalShaderMap(GMaxRHIFeatureLevel);
	if (Desc.Dimension == ETextureDimension::Texture3D)
	{
		const FIntVector Size(Desc.Extent.X, Desc.Extent.Y, Desc.Depth);
		FWeatherFill3DCS::FParameters* Parameters = GraphBuilder.AllocParameters<FWeatherFill3DCS::FParameters>();
		Parameters->Value = Value;
		Parameters->Size = Size;
		Parameters->Out3D = GraphBuilder.CreateUAV(Texture);
		FComputeShaderUtils::AddPass(GraphBuilder, RDG_EVENT_NAME("Weather.Fields.Fill3D"), TShaderMapRef<FWeatherFill3DCS>(ShaderMap),
			Parameters, FComputeShaderUtils::GetGroupCount(Size, FIntVector(4, 4, 4)));
	}
	else
	{
		const FIntVector Size(Desc.Extent.X, Desc.Extent.Y, 1);
		FWeatherFill2DCS::FParameters* Parameters = GraphBuilder.AllocParameters<FWeatherFill2DCS::FParameters>();
		Parameters->Value = Value;
		Parameters->Size = Size;
		Parameters->Out2D = GraphBuilder.CreateUAV(Texture);
		FComputeShaderUtils::AddPass(GraphBuilder, RDG_EVENT_NAME("Weather.Fields.Fill2D"), TShaderMapRef<FWeatherFill2DCS>(ShaderMap),
			Parameters, FComputeShaderUtils::GetGroupCount(Size, FIntVector(8, 8, 1)));
	}
```

```cpp
bool UWeatherFieldRegistry::FillUniform(FName Name, const FLinearColor& Value)
{
	UTextureRenderTarget* Target = Cast<UTextureRenderTarget>(GetOrCreateField(Name));
	FTextureRenderTargetResource* Resource = Target ? Target->GameThread_GetRenderTargetResource() : nullptr;
	if (!Resource)
	{
		return false;
	}
	const FVector4f V(Value.R, Value.G, Value.B, Value.A);
	ENQUEUE_RENDER_COMMAND(WeatherFillField)([Resource, V](FRHICommandListImmediate& RHICmdList)
	{
		FRDGBuilder GraphBuilder(RHICmdList);
		FRDGTextureRef Texture = Resource->GetRenderTargetTexture(GraphBuilder);
		WeatherGpu::AddFillPass(GraphBuilder, Texture, V);
		GraphBuilder.UseExternalAccessMode(Texture, ERHIAccess::SRVMask);
		GraphBuilder.Execute();
	});
	return true;
}

TArray<FLinearColor> UWeatherFieldRegistry::ReadTexelsBlocking(FName Name, TConstArrayView<FIntVector> Coords)
{
	TArray<FLinearColor> Result;
	UTextureRenderTarget* Target = Cast<UTextureRenderTarget>(FindField(Name));
	FTextureRenderTargetResource* Resource = Target ? Target->GameThread_GetRenderTargetResource() : nullptr;
	if (!Resource || Coords.Num() == 0)
	{
		return Result;
	}
	TArray<FIntVector4> Packed;
	for (const FIntVector& C : Coords)
	{
		Packed.Add(FIntVector4(C.X, C.Y, C.Z, 0));
	}
	TArray<FVector4f> Values;
	Values.SetNumZeroed(Packed.Num());
	FRHIGPUBufferReadback Readback(TEXT("Weather.ReadTexels"));
	ENQUEUE_RENDER_COMMAND(WeatherReadTexels)([Resource, &Packed, &Values, &Readback](FRHICommandListImmediate& RHICmdList)
	{
		const uint32 Bytes = Packed.Num() * sizeof(FVector4f);
		FRDGBuilder GraphBuilder(RHICmdList);
		FRDGTextureRef Texture = Resource->GetRenderTargetTexture(GraphBuilder);
		FRDGBufferRef Out = WeatherGpu::AddReadTexelsPass(GraphBuilder, Texture, Packed);
		AddEnqueueCopyPass(GraphBuilder, &Readback, Out, Bytes);
		GraphBuilder.UseExternalAccessMode(Texture, ERHIAccess::SRVMask);
		GraphBuilder.Execute();
		RHICmdList.SubmitAndBlockUntilGPUIdle();
		FMemory::Memcpy(Values.GetData(), Readback.Lock(Bytes), Bytes);
		Readback.Unlock();
	});
	FlushRenderingCommands();
	for (const FVector4f& V : Values)
	{
		Result.Add(FLinearColor(V.X, V.Y, V.Z, V.W));
	}
	return Result;
}
```

```cpp
void UWeatherSubsystem::UpdateLook(float RealDeltaSeconds)
{
	const EWeatherType Active = Orchestrator->ActiveType;
	if (Active != BlendTargetType)
	{
		BlendFromLook = DisplayedTypeLook;   // start from what is on screen (Review Focus 5)
		BlendTargetType = Active;
		BlendElapsed = 0.0;
		BlendDuration = bBlendNext ? Params.Sky.LookBlendSeconds : 0.0;
	}
	BlendElapsed += RealDeltaSeconds;
	const double Alpha = BlendDuration > 0.0 ? FMath::Clamp(BlendElapsed / BlendDuration, 0.0, 1.0) : 1.0;
	DisplayedTypeLook = FWeatherLook::Lerp(BlendFromLook, TypeLook(Active), Alpha);
	const FWeatherLook Season = FWeatherLook::Lerp(SeasonLook(Calendar.Season), SeasonLook(Calendar.NextSeason), Calendar.TransitionProgress);
	CurrentLook = FWeatherLook::Combine(DisplayedTypeLook, Season);
}

void UWeatherSubsystem::ApplyRig() const
{
	AWeatherDomain* D = Domain.Get();
	if (!D)
	{
		return;
	}
	auto Place = [](ADirectionalLight* Light, const FRotator& Rotation, double Lux)
	{
		if (!Light)
		{
			return;
		}
		USceneComponent* Root = Light->GetRootComponent();
		if (Root && Root->Mobility != EComponentMobility::Movable)
		{
			Root->SetMobility(EComponentMobility::Movable);   // a stationary light refuses SetActorRotation
		}
		Light->SetActorRotation(Rotation);
		Light->GetLightComponent()->SetIntensity(float(Lux));
	};
	Place(D->Sun, Rig.SunRotation, Rig.SunLux);
	Place(D->Moon, Rig.MoonRotation, Rig.MoonLux);
	if (D->SkyLight)
	{
		D->SkyLight->GetLightComponent()->SetIntensity(float(Rig.SkyLightIntensity));
	}
	if (D->HeightFog)
	{
		UExponentialHeightFogComponent* Fog = D->HeightFog->GetComponent();
		Fog->SetFogDensity(float(Rig.FogDensity));
		Fog->SetFogHeightFalloff(float(Rig.FogHeightFalloff));
	}
	if (D->PostProcess)
	{
		FPostProcessSettings& S = D->PostProcess->Settings;
		S.bOverride_WhiteTemp = true;
		S.WhiteTemp = float(Rig.WhiteTemp);
		S.bOverride_ColorSaturation = true;
		S.ColorSaturation = FVector4(Rig.Saturation, Rig.Saturation, Rig.Saturation, 1.0);
		S.bOverride_ColorContrast = true;
		S.ColorContrast = FVector4(Rig.Contrast, Rig.Contrast, Rig.Contrast, 1.0);
		S.bOverride_AutoExposureBias = true;
		S.AutoExposureBias = float(Rig.ExposureBias);
	}
```
